AI Glossary

StableLast verified: 2026-10-06

Term → Definition → Example → Related concepts. Full explanations live in each term's dedicated topic file; this page is the fast-lookup reference.

A

Agent. A system where an LLM dynamically decides a sequence of actions to accomplish a goal. Example: a research agent deciding which searches to run. Related: AI Agents.
Agentic RAG. RAG where an agent iteratively plans, retrieves, and refines instead of one-shot retrieval. Related: Advanced RAG.
A2A (Agent-to-Agent Protocol). A standard for independent agents to discover and collaborate with each other. Related: A2A.
Attention. A mechanism letting a model weigh the relevance of all positions in a sequence to each other. Related: Transformers.

B

BM25. A lexical ranking algorithm scoring documents by term frequency/rarity. Related: Advanced RAG.
Backpropagation. The algorithm computing gradients of loss w.r.t. every weight via the chain rule. Related: Deep Learning.

C

Chain-of-thought (CoT). Explicit step-by-step reasoning generated before a final answer. Related: Advanced Prompting.
Context window. The maximum tokens (input+output) a model can process per request. Related: Tokens & Context Window.
Circuit breaker. A pattern that stops calls to a failing dependency after repeated failures. Related: Performance and Scaling.

D

Discriminative model. Learns P(label|input); draws a decision boundary. Related: Generative vs Discriminative.

E

Embedding. A dense vector representation of data such that similar items are close in vector space. Related: Embeddings.
Excessive agency. Granting an agent more autonomy/permission than its task requires. Related: AI Security.

F

Faithfulness. Whether every claim in a generated answer is supported by the retrieved context. Related: AI Evaluation.
Fine-tuning. Further training a pretrained model's weights on a task-specific dataset. Related: Fine-Tuning.

G

Generative model. Learns P(input); can be sampled to produce new data. Related: Generative vs Discriminative.
Graph RAG. RAG that retrieves via knowledge graph traversal. Related: Graph RAG.

H

Hallucination. Fluent but factually incorrect or unsupported LLM output. Related: Sampling & Hallucination.
HNSW. A graph-based approximate nearest neighbor indexing algorithm. Related: Vector Databases.

I

Indirect prompt injection. Malicious instructions embedded in external content processed by the model. Related: AI Security.

K

KV cache. Cached attention keys/values avoiding recomputation during generation. Related: Transformers.
Knowledge graph. Entities (nodes) and relationships (edges) representing connected information. Related: Knowledge Graphs.

L

LCEL. LangChain Expression Language — the `|` syntax for composing Runnables. Related: LangChain.
LLM-as-judge. Using a separate LLM call to score another LLM's output. Related: AI Evaluation.
LoRA. Low-Rank Adaptation — parameter-efficient fine-tuning via small trainable matrices. Related: Fine-Tuning.

M

MCP (Model Context Protocol). A standard connecting AI hosts to tools, data, and prompts. Related: MCP.
Multi-head attention. Running several attention computations in parallel to capture different relationship types. Related: Transformers.

P

PagedAttention. vLLM's non-contiguous KV cache memory management technique. Related: LLM Inference.
Prompt injection. An attempt to override model instructions via crafted input. Related: AI Security.

Q

Quantization. Reducing model weight precision to shrink memory footprint. Related: Local LLMs.
QLoRA. LoRA combined with quantizing the frozen base model. Related: Fine-Tuning.

R

RAG (Retrieval-Augmented Generation). Retrieving relevant documents and injecting them into the prompt. Related: RAG.
ReAct. Reason+Act agent pattern: interleaved reasoning and tool-call actions. Related: AI Agents.
Reranking. Re-scoring retrieved candidates more precisely via a cross-encoder. Related: Advanced RAG.
RLHF. Reinforcement Learning from Human Feedback, used to align LLMs. Related: What is an LLM.

S

Self-attention. Each token computes weighted relevance to every other token. Related: Transformers.
Supervisor pattern. A coordinating agent that delegates to specialist agents. Related: Agentic AI.

T

Temperature. Controls randomness of next-token sampling. Related: Sampling & Hallucination.
Tool calling. An LLM requesting a defined function be executed with structured arguments. Related: Tool Calling.
Trace / Span. A trace is a full request's execution record; a span is one step within it. Related: LLM Observability.
Token. A sub-word unit the model actually processes. Related: Tokens & Context Window.

V

vLLM. A purpose-built LLM inference serving engine with PagedAttention. Related: LLM Inference.
