AI Cheat Sheets — Consolidated Quick Reference

StableLast verified: 2026-10-06

Every cheat sheet below is pulled from its topic file's own section 33 — this page consolidates them for rapid pre-interview speed-review.

LLM Cheat Sheet

LLM = transformer trained to predict next tokens → pretrained → instruction-tuned → RLHF/DPO-aligned → optionally reasoning-trained. Every API call is pure inference: tokenize → embed → attend → sample → repeat. Temperature/top-p/top-k control sampling randomness. Hallucination is structural — ground with RAG.

Prompt Engineering Cheat Sheet

Be specific about: role, task, format, constraints, audience. Prefer few-shot for format consistency. Use system prompts for stable behavior. Treat all untrusted text as data, not instructions. CoT for multi-step reasoning. Chain prompts for complex tasks. Always evaluate changes against a golden set.

RAG Cheat Sheet

Documents → Loader → Parser → Chunker → Embedding → Vector DB → Retriever → Context → LLM → Answer. Require citations + "I don't know" fallback. Tune chunking/retrieval precision empirically. Enforce access-control-aware filtering. Hybrid search + reranking for production precision.

LangChain Cheat Sheet

Model + Prompt + Output Parser composed via LCEL (`|`) into Chains. Retriever → RAG chain. Tools + Agent loop → tool-calling/agent apps. Use LangGraph for complex agents. Enable LangSmith for tracing/eval.

LangGraph Cheat Sheet

State + Nodes + Edges (conditional/cyclic) + Checkpointer. Use for agents needing loops, branching, persistence, or human-in-the-loop. Always bound cycles; use a durable checkpointer in production.

MCP Cheat Sheet

Host → Client → Server (stdio/local or HTTP-SSE/remote) → external system. Exposes Tools, Resources, Prompts. Discovery removes need for hardcoded integration knowledge. Validate server-side, scope tightly, auth for remote.

Agent Cheat Sheet

LLM app = 1 call. Workflow = fixed steps. Agent = LLM decides steps dynamically (ReAct: reason → act → observe → repeat). Planner/Executor = decompose then execute. Supervisor = route to specialists + integrate. Reflection/Critic = evaluate + revise. Use the simplest type that solves the task.

Vector DB Cheat Sheet

Vector DB = ANN indexing (HNSW/IVF) + metadata filtering + optional hybrid search. Enforce tenant isolation at the query layer, always. pgvector (reuse Postgres), Pinecone (managed), Qdrant/Weaviate (flexible filtering), Milvus (massive scale), Chroma (prototyping).

Evaluation Cheat Sheet

Golden dataset + LLM-as-judge (calibrated) + human review = offline gate. Sample production traffic = online monitoring. RAG: faithfulness, relevance, context precision/recall. Agents: tool success rate, task completion. Never ship without evaluation.

AI Security Cheat Sheet

Prompt injection (direct/indirect) has no complete fix — delimit untrusted content, least-privilege tool scoping, human approval for high-risk actions, audit log everything. Defense-in-depth, not a single silver bullet.

AI System Design Cheat Sheet

Requirements → Architecture → Data flow → Stores → Models → Security → Observability → Scaling → Failure handling → Cost → Trade-offs. Quantify scale. Address security/observability/failure handling always. State trade-offs explicitly.

Cost Optimization Cheat Sheet

Model routing (cheap vs frontier) + prompt caching (stable prefixes) + semantic caching (tuned threshold) + batch API (non-real-time) + context reduction. Always validate against an eval set — never trade quality blindly for cost.
