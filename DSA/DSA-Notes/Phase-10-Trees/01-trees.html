Phase 10 · Trees

Trees — From Beginner Level 🌳

Non-linear hierarchy data structure — traversals, BST, aur interview mein sabse zyada poochhe jaane wale tree problems, sab Hinglish mein.

1. Trees — Concept

1. What is it?

Tree ek non-linear data structure hai jisme nodes ek hierarchy mein connected hote hain — ek "root" se shuru hoke neeche branches mein failte hain, bilkul ek ulte pede ki tarah.

2. Why Needed?

Arrays/Linked Lists linear hain — sirf ek order mein data store hota hai. Real duniya ka bahut sa data hierarchical hota hai (file systems, org charts, HTML DOM, decision trees) — waha Tree structure natural fit hai. BST jaisa special tree fast search (O(log n)) bhi deta hai, jo sorted array insert/delete se better hai.

3. Real-Life Analogy

📝 Family Tree
Dada-dadi (root) ke bachche (children), unke bachche (grandchildren)... har person ka ek hi "parent" hota hai upar, lekin multiple "children" ho sakte hain neeche. Jinke koi bachche nahi (last generation), wo "leaf" nodes hain.

4. Core Terminology

TermMeaning
RootSabse upar wala node (koi parent nahi)
ParentEk node jiske "child" nodes hain neeche
ChildEk node jo kisi doosre node se neeche connected hai
LeafNode jiske koi children nahi (end of a branch)

5. Binary Tree & BST + Diagram

Binary Tree: Har node ke max 2 children ho sakte hain (left aur right).

Binary Search Tree (BST): Ek special Binary Tree jisme left subtree ki saari values < node, aur right subtree ki saari values > node — ye property har node par recursively true hoti hai.

Binary Search Tree:
              8
            /   \
           3     10
          / \      \
         1   6      14
            / \     /
           4   7   13

Left of 8 (3,1,6,4,7) sab < 8
Right of 8 (10,14,13) sab > 8
Yehi property har node par hai — isse "search" fast ban jata hai!
Tree Node + BST Insert
class TreeNode {
  constructor(value) {
    this.value = value;
    this.left = null;
    this.right = null;
  }
}

function insertBST(root, value) {
  if (!root) return new TreeNode(value); // base case: empty spot found
  if (value < root.value) root.left = insertBST(root.left, value);
  else root.right = insertBST(root.right, value);
  return root;
}

Why BST search is fast: Bilkul Binary Search jaisa — har node par tum "left ya right" decide karte ho, aur ek pura subtree discard kar dete ho. Balanced BST mein search O(log n) hai.

BST Search
function searchBST(root, target) {
  if (!root) return null;                    // not found
  if (root.value === target) return root;      // found!
  if (target < root.value) return searchBST(root.left, target);
  return searchBST(root.right, target);
}

6. Tree Traversals — The Four Ways to Visit Every Node

Same tree se example lete hain:

              8
            /   \
           3     10
          / \      \
         1   6      14
💡 The 3 DFS-style Traversals — remember by WHERE you visit the root
  • Preorder (Root → Left → Right): Root pehle visit karo. → 8, 3, 1, 6, 10, 14
  • Inorder (Left → Root → Right): Root beech mein visit karo. → 1, 3, 6, 8, 10, 14 (⭐ for a BST, this gives SORTED order!)
  • Postorder (Left → Right → Root): Root aakhri mein visit karo. → 1, 6, 3, 14, 10, 8
function preorder(root, result = []) {
  if (!root) return result;
  result.push(root.value);   // Root first
  preorder(root.left, result);
  preorder(root.right, result);
  return result;
}

function inorder(root, result = []) {
  if (!root) return result;
  inorder(root.left, result);
  result.push(root.value);   // Root in the middle
  inorder(root.right, result);
  return result;
}

function postorder(root, result = []) {
  if (!root) return result;
  postorder(root.left, result);
  postorder(root.right, result);
  result.push(root.value);   // Root last
  return result;
}
🎯 Important Fact for Interviews
Inorder traversal of a BST always gives elements in sorted order. Ye ek most-commonly tested fact hai — agar BST ke elements sorted chahiye, bas inorder traversal karo, alag se sort karne ki zarurat nahi.

Level Order Traversal (BFS on a tree)

Ye tree ko level by level (top to bottom, left to right) visit karta hai — Queue use karke.

function levelOrder(root) {
  if (!root) return [];
  const result = [];
  const queue = [root];
  while (queue.length) {
    const levelSize = queue.length;
    const currentLevel = [];
    for (let i = 0; i < levelSize; i++) {
      const node = queue.shift();
      currentLevel.push(node.value);
      if (node.left) queue.push(node.left);
      if (node.right) queue.push(node.right);
    }
    result.push(currentLevel);
  }
  return result;
}
// Output: [[8], [3,10], [1,6,14]]

Line-by-line: Root ko queue mein daalo. Har iteration mein current queue size (levelSize) note karo — ye batata hai kitne nodes is level par hain. Unhe process karke unke children queue mein add karo (agle level ke liye).

7. Dry Run — Level Order

📝 Step by step
Queue=[8]. levelSize=1: pop 8, add 3,10 to queue. result=[[8]]
Queue=[3,10]. levelSize=2: pop 3(add 1,6), pop 10(add 14). result=[[8],[3,10]]
Queue=[1,6,14]. levelSize=3: pop all, no children. result=[[8],[3,10],[1,6,14]]

8. Time / Space Complexity

OperationTimeSpace
Any traversal (visit all nodes)O(n)O(h) recursion stack (h=height), O(n) for level order (queue)
BST Search/Insert (balanced)O(log n)O(log n)
BST Search/Insert (skewed/unbalanced)O(n) worst case!O(n)
⚠️ BST Isn't Always O(log n)!
Agar tum ek already-sorted array ko ek BST mein insert karo one by one, wo ek "skewed" tree ban jata hai (bilkul linked list jaisa) — search O(n) ho jata hai! Isliye "self-balancing" trees (AVL, Red-Black) exist karte hain.

9. When Should I Use Trees? — Checklist

🎯 Checklist
  • Hierarchical data (file systems, org charts, HTML DOM)
  • Need fast search + maintain sorted order dynamically → BST
  • "Level by level" processing → Level Order (BFS)
  • Need to process children before parent (e.g. deleting folders) → Postorder

10. Common Mistakes

  • Preorder/Inorder/Postorder order confuse karna — yaad rakho: naam mein "pre/in/post" batata hai root kab visit hota hai relative to children.
  • Null checks bhool jaana (if (!root) return) — recursion crash ho jayegi.
  • BST insert mein duplicate values ka case na sochna.
  • Diameter/height jaise problems mein global max ko galat jagah update karna (root return value se confuse ho jaana).

11. Interview Tips

Jab bhi tree problem mile, poochho: "Binary Tree hai ya BST?" (BST property use ho sakti hai optimization ke liye). Aur socho: "Kya mujhe DFS (pre/in/post-order via recursion) chahiye ya BFS (level order via queue)?" — most tree problems in dono mein se ek pattern follow karte hain.

Interview Questions — Trees

Easy

Q1. Maximum Depth of Binary TreeEasy
Pattern: Recursion

Given the root of a binary tree, return its maximum depth (number of nodes on the longest path from root to a leaf).

Example: Tree [3,9,20,null,null,15,7] → depth = 3

Hint: Base case null returns 0. Otherwise depth = 1 + max(depth(left), depth(right)).
Q2. Invert / Mirror a Binary TreeEasy
Pattern: Recursion with swap

Given the root of a binary tree, invert it so left and right children are swapped at every node, and return the root.

Example: [4,2,7,1,3,6,9] → [4,7,2,9,6,3,1]

Hint: Recursively swap left and right children at every node, then recurse into the (now-swapped) children.
Q3. Same TreeEasy
Pattern: Recursion comparison

Given the roots of two binary trees, check if they are structurally identical and have the same node values.

Example: p=[1,2,3], q=[1,2,3] → true

Hint: Both null → true; one null → false; values differ → false; else recursively check left subtrees AND right subtrees.
Q4. Level Order TraversalEasy
Pattern: BFS with Queue

Return the level order traversal of a binary tree's node values (grouped by level, left to right).

Example: [3,9,20,null,null,15,7] → [[3],[9,20],[15,7]]

Hint: Use a queue; track levelSize each iteration to know when one level ends and the next begins. See levelOrder code above.
Q5. Search in a BSTEasy
Pattern: BST property

Given a BST root and a target value, return the subtree rooted at the node with that value, or null if not found.

Example: root=[4,2,7,1,3], target=2 → [2,1,3]

Hint: Use the BST ordering — go left if target < node.value, right if greater, stop when equal or null.

Medium

Q6. Validate Binary Search TreeMedium
Pattern: Recursion with range bounds

Determine if a given binary tree is a valid BST (not just checking parent-child, but the whole subtree range).

Example: [5,1,4,null,null,3,6] → false (4's left child 3 < 5 but 3 is in 4's subtree which must be > 5's... actually 4 < 5 violates right subtree rule)

Hint: Pass down a valid (min, max) range for each node as you recurse — narrow the range going left (update max) or right (update min). Just comparing to immediate parent is not enough.
Q7. Lowest Common Ancestor of a BSTMedium
Pattern: BST property

Given a BST and two node values p, q, find their lowest common ancestor.

Example: root=[6,2,8,0,4,7,9], p=2, q=8 → 6

Hint: Starting at root: if both p and q are less than current node, go left; if both greater, go right; otherwise current node is the LCA.
Q8. Diameter of Binary TreeMedium
Pattern: Recursion returning multiple values

Find the length of the longest path between any two nodes in a binary tree (may or may not pass through root).

Example: [1,2,3,4,5] → diameter = 3 (path 4-2-1-3 or 5-2-1-3)

Hint: The diameter through any node = height(left) + height(right). Compute height recursively while tracking a running max across all nodes, not just the root.
Q9. Binary Tree Right Side ViewMedium
Pattern: Level order / DFS with depth tracking

Return the values visible when looking at the binary tree from the right side, top to bottom.

Example: [1,2,3,null,5,null,4] → [1,3,4]

Hint: Do level order traversal and take the last node of each level, or DFS (right first) tracking depth and only recording the first node seen at each depth.
Q10. Kth Smallest Element in a BSTMedium
Pattern: Inorder traversal

Given a BST, find the kth smallest value in it.

Example: root=[3,1,4,null,2], k=1 → 1

Hint: Inorder traversal of a BST visits nodes in sorted order — stop after the kth visited node (early-exit for efficiency).

Hard

Q11. Construct Binary Tree from Preorder and Inorder TraversalHard
Pattern: Recursive construction

Given preorder and inorder traversal arrays of a binary tree, reconstruct and return the tree.

Example: preorder=[3,9,20,15,7], inorder=[9,3,15,20,7] → tree [3,9,20,null,null,15,7]

Hint: The first element of preorder is always the root. Find its position in inorder to split into left/right subtrees, then recurse using the corresponding slices of preorder for each side.
Q12. Binary Tree Maximum Path SumHard
Pattern: Recursion with global max tracking

Find the maximum path sum in a binary tree, where a path can start and end at any node (does not need to pass through root).

Example: [-10,9,20,null,null,15,7] → 42 (path 15→20→7)

Hint: For each node, compute the max "downward" contribution it can offer its parent (ignore negative subtree sums), but also update a separate global max using left + right + node value (a path bending at this node).
Q13. Serialize and Deserialize Binary TreeHard
Pattern: Preorder with null markers

Design an algorithm to serialize a binary tree to a string and deserialize that string back to the original tree structure.

Example: [1,2,3,null,null,4,5] → serialized string → deserialize → same tree

Hint: Do a preorder DFS, writing a sentinel (like "#") for null children. Deserialize by reading tokens in the same preorder sequence, recursively rebuilding nodes.
Q14. Vertical Order Traversal of a Binary TreeHard
Pattern: BFS/DFS with coordinate tracking

Given a binary tree, return the vertical order traversal grouped by column, then by row, then sorted by value for ties.

Example: [3,9,20,null,null,15,7] → [[9],[3,15],[20],[7]]

Hint: Track (column, row) for each node via BFS/DFS (left: col-1, right: col+1). Group by column in a map, sort within group by row then value, then output columns left to right.
