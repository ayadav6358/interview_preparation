Contribution Technique

Har element ka total answer mein "contribution" nikaal kar O(n²)/O(n³) se O(n) tak optimize karna.

← Prev: Two Pointers Next: Strings →

1. What is it?

Contribution Technique ek problem-solving mindset hai jisme, instead of directly calculating the final answer, hum sochte hain: "har individual element total answer mein kitna 'contribute' kar raha hai?" Phir sabke contributions add kar dete hain.

2. Why is it useful?

Kai problems mein "sum over all subarrays" ya "sum over all pairs" jaisa kuch poocha jata hai. Har subarray/pair ko individually generate karke sum karna O(n²) ya O(n³) lagta hai. Contribution Technique se hum seedha calculate karte hain ki har element kitne subarrays/pairs mein appear hota hai, aur uska total contribution ek formula se nikal lete hain — often O(n).

3. Real-Life Analogy

📝 Class Photo Analogy
Socho tumhe count karna hai "total kitni baar har student kisi group photo mein appear hua" agar sabhi possible group combinations li jaye. Har group ko individually list karne ke bajaye (bahut saare groups!), tum directly calculate kar sakte ho: "ek particular student kitne groups mein hoga" — usko formula se seedha nikal lo.

4. How to Calculate Contribution — The Core Idea

Classic example: Sum of all subarray sums. Ek element arr[i] kitne subarrays mein appear hota hai?

arr[i] index se subarray start ho sakta hai (i+1) tareeko se: [0..i], [1..i], ..., [i..i]
arr[i] index par subarray end ho sakta hai (n-i) tareeko se: [i..i], [i..i+1], ..., [i..n-1]

Total subarrays jisme arr[i] shaamil hai = (i + 1) * (n - i)

Contribution of arr[i] to the final answer = arr[i] * (i + 1) * (n - i)

5. Visual Diagram

arr = [1, 2, 3],  n = 3

For arr[0]=1: appears in (0+1)*(3-0) = 1*3 = 3 subarrays
  → [1], [1,2], [1,2,3]   (yes, 3 subarrays contain index 0)

For arr[1]=2: appears in (1+1)*(3-1) = 2*2 = 4 subarrays
  → [2], [1,2], [2,3], [1,2,3]

For arr[2]=3: appears in (2+1)*(3-2) = 3*1 = 3 subarrays
  → [3], [2,3], [1,2,3]

Total sum of all subarray sums = 1*3 + 2*4 + 3*3 = 3 + 8 + 9 = 20

6. Code + Explanation

JavaScript — Brute Force
function sumOfSubarraySumsBrute(arr) {
  let total = 0;
  for (let i = 0; i < arr.length; i++) {
    let sum = 0;
    for (let j = i; j < arr.length; j++) {
      sum += arr[j];
      total += sum; // add this subarray's sum
    }
  }
  return total;
}

Ye har subarray generate karke uska sum add kar raha hai — O(n²) time.

JavaScript — Optimal (Contribution Technique)
function sumOfSubarraySumsOptimal(arr) {
  const n = arr.length;
  let total = 0;
  for (let i = 0; i < n; i++) {
    const timesAppears = (i + 1) * (n - i);
    total += arr[i] * timesAppears;
  }
  return total;
}

Why faster: Hum direct formula se calculate kar rahe hain ki har element kitni baar count hoga, bina actually har subarray generate kiye. Single loop → O(n).

7. Dry Run

📝 arr = [1, 2, 3]
i=0: (0+1)*(3-0)=3, contribution = 1*3 = 3, total=3
i=1: (1+1)*(3-1)=4, contribution = 2*4 = 8, total=11
i=2: (2+1)*(3-2)=3, contribution = 3*3 = 9, total=20 ✅

8. Complexity

Brute Force: Time O(n²), Space O(1). Optimal (Contribution): Time O(n), Space O(1) — huge improvement.

When Should I Use It? — Checklist

🎯 Use Contribution Technique when:
  • Question asks for a sum/count over all subarrays/subsequences/pairs
  • Aap directly answer nahi nikal sakte, but har element ka "role" (kitni baar count hoga) predictable hai
  • Common in: "sum of minimums of all subarrays", "sum of all subarray sums", "count of pairs with some property"

Common Mistakes

  • Formula galat lagana — hamesha chhoti example (jaise n=3) par haath se verify karo pehle.
  • Overcounting ya undercounting — boundary cases (pehla/aakhri element) carefully check karo.
  • Duplicate values wale array mein monotonic stack ka strict vs non-strict comparison sahi na rakhna (double counting ho sakta hai).

Interview Tips

Ye ek advanced/clever pattern hai — jab tum ise use karo, interviewer ko explain zaroor karo "main directly answer nahi nikaal raha, balki har element ka contribution calculate kar raha hoon total answer mein" — ye samajhna interviewer ko impress karta hai kyunki ye ek non-obvious insight hai.

Interview Questions

Easy Section

Q1. Sum of All Subarray SumsEasy

Compute the sum of sums of all contiguous subarrays.

Input: [1,2,3] → Output: 20
Hint: For each i, contribution = arr[i] * (i+1) * (n-i). Sum all contributions.
Q2. Count Subarrays Containing a Specific IndexEasy

Given index i and array length n, count how many subarrays include index i.

Input: n=5, i=2 → Output: 9
Hint: Number of (start, end) combinations that include index i is (i+1)*(n-i) — a direct formula, no enumeration needed.
Q3. Count Pairs with Given DifferenceEasy

Count pairs (i, j) where arr[i] - arr[j] equals a given difference k.

Input: [1,5,3,4,2], k=3 → Output: 2
Hint: Use a frequency hashmap; for each element, check how many previous elements satisfy the difference condition — each match contributes 1 to the answer.
Q4. Total Appearances Across All Subsets of Size 2Easy

Given n elements, how many pairs (2-element subsets) include a specific element?

Input: n=5 → Output: 4 (pairs with any one fixed element)
Hint: Each element pairs with every other element exactly once — that's (n-1) pairs per element.
Q5. Sum of Left-Right Boundary ContributionsEasy

Given a fixed position, count how many valid (start,end) ranges in an array include it.

Input: n=6, position=3 → Output: 4*3 = 12
Hint: Think in terms of "how many valid ranges include this position" — same left-count × right-count multiplication idea.

Medium Section

Q6. Sum of Subarray MinimumsMedium

Find the sum of the minimum of every contiguous subarray.

Input: [3,1,2,4] → Output: 17
Hint: For each element, find how far left/right it remains the minimum using a monotonic stack, then contribution = arr[i] * leftCount * rightCount.
Q7. Sum of Subarray Ranges (max - min)Medium

Find the sum of (max - min) over all contiguous subarrays.

Input: [1,2,3] → Output: 4
Hint: Compute "sum of subarray maximums" and "sum of subarray minimums" separately using contribution + monotonic stack, then subtract.
Q8. Count Subarrays With Product Less Than KMedium

Count contiguous subarrays whose product is strictly less than k.

Input: [10,5,2,6], k=100 → Output: 8
Hint: Use a sliding window; whenever the window is valid, add (right - left + 1) to the count — this counts all subarrays ending at 'right' that are valid.
Q9. Count of Range SumMedium

Count the number of subarrays whose sum lies within [lower, upper].

Input: [-2,5,-1], lower=-2, upper=2 → Output: 3
Hint: Use prefix sums plus a counting structure (like a modified merge sort or BIT) to count how many earlier prefix sums fall within the needed range for each position.
Q10. Number of Subsequences That Satisfy a Sum ConditionMedium

Count subsequences where min+max ≤ target.

Input: [3,5,6,7], target=9 → Output: 4
Hint: Sort the array, use two pointers; for a fixed left (min), all elements up to the matching right can freely be included or not — contributes 2^(count) subsequences.

Hard Section

Q11. Sum of Widths of SubsequencesHard

Sum of (max - min) over all non-empty subsequences of an array.

Input: [2,1,3] → Output: 6
Hint: Sort the array. For each element as the max of a subsequence, count 2^(elements smaller than it) as multiplier; similarly for min — sum contributions using this combinatorial formula.
Q12. Total Strength of WizardsHard

For every subarray, strength = min(subarray) * sum(subarray). Find total strength over all subarrays, modulo 1e9+7.

Input: [1,3,1,2] → Output: 44
Hint: Combine a monotonic stack (to find each element's range as minimum) with prefix-sum-of-prefix-sums to compute each minimum's weighted contribution efficiently.
Q13. Sum of Subsequence Widths with Weighted PositionsHard

Given weights per index, compute sum of (max-min) * (position-based weight) over all subsequences.

Input: values=[1,3,5], weights=[2,1,3] → Output: problem-specific combinatorial sum
Hint: Extend the sorted + power-of-2 contribution idea, but now also fold in the weight of the subsequence's contributing positions using prefix sums of weights.
