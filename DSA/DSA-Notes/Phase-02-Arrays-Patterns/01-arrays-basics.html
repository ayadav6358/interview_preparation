Phase 2 · Arrays & Patterns

Arrays — Basics

Array kya hai, kaise store hota hai memory mein, aur basic operations ki complexity.

← Prev: Time & Space Complexity Next: Prefix Sum →

1. What is it?

Array ek contiguous (side-by-side) block of memory hai jisme same type ki values ek order mein rakhi jaati hain, aur har value ko ek index (position number, 0 se start) se access kiya jata hai.

2. Why do we need it?

Agar har value alag jagah memory mein rakhi ho, unhe dhundhna slow hoga. Array mein sab kuch ek saath, order mein hone se, index se seedha O(1) mein access mil jata hai.

3. Real-Life Analogy

📝 Train Compartments
Train ke compartments socho — S1, S2, S3... har compartment ka number fix hai. Tumhe seedha "S5 mein chalo" bol sakte ho, dhundhna nahi padta. Ye hi array indexing hai.

4. Operations + Diagram

Index:   0    1    2    3    4
Value:  [10,  20,  30,  40,  50]

Access arr[2]   → O(1)  (seedha jump)
Search value 40 → O(n)  (worst case pura array check)
Insert at end   → O(1)  (agar space hai)
Insert at start → O(n)  (sabko ek position right shift karna padta hai)
Delete at start → O(n)  (sabko ek position left shift karna padta hai)
JavaScript — Basic Operations
let arr = [10, 20, 30, 40, 50];

// Traversal
for (let i = 0; i < arr.length; i++) console.log(arr[i]);

// Insertion at end
arr.push(60);          // O(1) amortized

// Insertion at start
arr.unshift(5);        // O(n) - shifts everyone right

// Deletion at end
arr.pop();              // O(1)

// Deletion at start
arr.shift();            // O(n) - shifts everyone left

// Search
let index = arr.indexOf(30); // O(n)

// Update
arr[2] = 99;            // O(1)

2D Arrays

2D array matlab "array of arrays" — grid jaisa. Jaise chess board (8x8) ya ek Excel sheet.

let grid = [
  [1, 2, 3],
  [4, 5, 6],
  [7, 8, 9]
];
console.log(grid[1][2]); // row 1, col 2 → 6

for (let row = 0; row < grid.length; row++) {
  for (let col = 0; col < grid[row].length; col++) {
    console.log(grid[row][col]);
  }
}

Dry Run — Insert at Start

📝 arr = [10, 20, 30], unshift(5)
Step 1: 30 shifts right → [10, 20, _, 30]
Step 2: 20 shifts right → [10, _, 20, 30]
Step 3: 10 shifts right → [_, 10, 20, 30]
Step 4: 5 placed at index 0 → [5, 10, 20, 30]
Total shifts = n → O(n)

Complexity Summary

OperationTimeSpace
Access by indexO(1)O(1)
Search (unsorted)O(n)O(1)
Insert/Delete at endO(1) amortizedO(1)
Insert/Delete at start/middleO(n)O(1)

When Should I Use It? — Checklist

🎯 Use Arrays when:
  • Fast index-based access chahiye
  • Data ka order matter karta hai aur mostly fixed size hai
  • Bahut zyada insert/delete at start/middle nahi ho raha (warna Linked List consider karo)

Common Mistakes

⚠️ Common Mistakes
  • Start/end mein insert-delete ko O(1) samajhna — sirf END par O(1) hai, start par O(n).
  • 2D array mein row/column index ulta likh dena — hamesha grid[row][col] yaad rakho.
  • Out-of-bounds index access karna (returns undefined in JS silently, jo bugs chhupa deta hai).

Interview Tips

Array problems mein pehle poocho: "Sorted hai kya? Duplicates ho sakte hain? Negative numbers hain?" — ye clarifications aksar batate hain kaunsa pattern (Two Pointers, Prefix Sum, Sliding Window) use hoga.

Interview Questions

Easy Section

Q1. Two SumEasy

Find indices of two numbers that add up to target.

Input: arr=[2,7,11,15], target=9 → Output: [0,1]
Hint: Use a hashmap to store seen values for O(1) lookup of the complement.
Q2. Move ZeroesEasy

Move all zeroes to the end while keeping relative order of non-zero elements, in-place.

Input: [0,1,0,3,12] → Output: [1,3,12,0,0]
Hint: Use a slow pointer that tracks where the next non-zero should go.
Q3. Find Maximum and Minimum in ArrayEasy

Find both max and min in a single pass.

Input: [3,7,1,9,4] → Output: max=9, min=1
Hint: Track two running variables while looping once — no need for two separate passes.
Q4. Rotate Array by K StepsEasy

Rotate array to the right by k steps.

Input: [1,2,3,4,5,6,7], k=3 → Output: [5,6,7,1,2,3,4]
Hint: Think about reversing the whole array, then reversing the two parts separately.
Q5. Remove Duplicates from Sorted ArrayEasy

Remove duplicates in-place from a sorted array, return new length.

Input: [1,1,2,2,3] → Output: 3, array becomes [1,2,3,...]
Hint: Two pointers — slow tracks last unique position, fast scans ahead.

Medium Section

Q6. Maximum Subarray (Kadane's Algorithm)Medium

Find the contiguous subarray with the largest sum.

Input: [-2,1,-3,4,-1,2,1,-5,4] → Output: 6 (subarray [4,-1,2,1])
Hint: At each index, decide whether to extend the previous subarray or start fresh — track running sum and reset when it goes negative.
Q7. Majority ElementMedium

Find the element that appears more than n/2 times.

Input: [2,2,1,1,1,2,2] → Output: 2
Hint: Boyer-Moore voting algorithm — maintain a candidate and a count, in O(1) space.
Q8. Product of Array Except SelfMedium

Return array where each element is the product of all other elements, without division.

Input: [1,2,3,4] → Output: [24,12,8,6]
Hint: Build prefix product from the left and suffix product from the right, then multiply.
Q9. Merge IntervalsMedium

Merge all overlapping intervals.

Input: [[1,3],[2,6],[8,10]] → Output: [[1,6],[8,10]]
Hint: Sort intervals by start time first, then sweep through merging overlapping ones.
Q10. Next PermutationMedium

Rearrange numbers into the lexicographically next greater permutation.

Input: [1,2,3] → Output: [1,3,2]
Hint: Find the rightmost ascending pair, swap with next larger element to its right, then reverse the suffix.

Hard Section

Q11. First Missing PositiveHard

Find the smallest missing positive integer in O(n) time, O(1) extra space.

Input: [3,4,-1,1] → Output: 2
Hint: Use the array itself as a hash table — place each value v at index v-1 by swapping in-place.
Q12. Trapping Rain WaterHard

Given elevation heights, compute how much water can be trapped after raining.

Input: [0,1,0,2,1,0,1,3,2,1,2,1] → Output: 6
Hint: For each position, trapped water = min(leftMax, rightMax) - height. Use two pointers with running max on each side.
Q13. Median of Two Sorted ArraysHard

Find the median of two sorted arrays in O(log(min(m,n))) time.

Input: nums1=[1,3], nums2=[2] → Output: 2.0
Hint: Binary search on the smaller array to find the correct partition point between both arrays.
