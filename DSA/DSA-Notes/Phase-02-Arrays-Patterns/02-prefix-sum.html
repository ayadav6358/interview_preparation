Phase 2 · Arrays & Patterns

Prefix Sum

Range sum queries ko O(1) mein answer karne ka precompute technique.

← Prev: Arrays Basics Next: Sliding Window →

1. What is it?

Prefix Sum ek array hai jisme prefix[i] = arr[0] + arr[1] + ... + arr[i] — matlab shuru se lekar index i tak ka running total.

2. Why do we need it?

Agar tumse baar-baar poocha jaye "index L se R tak ka sum kya hai" (Range Sum Query), aur ye query bahut baar (Q times) aaye, to har baar loop chala kar sum karna slow hoga: O(Q × n). Prefix Sum se hum ek baar precompute karke har query O(1) mein answer de sakte hain.

3. Real-Life Analogy

📝 Odometer Analogy
Car ka odometer total distance batata hai start se ab tak. Agar tumhe pata karna hai "10 km ke marker se 50 km ke marker tak kitni distance hui", tum bas odometer(50) - odometer(10) kar sakte ho — poori journey dobara measure nahi karni padti. Yehi Prefix Sum ka idea hai.

4. How Does It Work? + Formula

prefix[0] = arr[0]
prefix[i] = prefix[i-1] + arr[i]

Range Sum Query (L to R):
  if L == 0: sum = prefix[R]
  else:      sum = prefix[R] - prefix[L-1]

5. Visual Diagram

arr:     [2, 4, 1, 5, 3]
prefix:  [2, 6, 7, 12, 15]
           ↑  ↑  ↑   ↑   ↑
        sum till index 0,1,2,3,4

Query: sum from index 1 to 3 (values 4,1,5 = 10)
= prefix[3] - prefix[0] = 12 - 2 = 10 ✅

6. Code + Explanation

JavaScript — Brute Force (no prefix sum)
function rangeSumBrute(arr, L, R) {
  let sum = 0;
  for (let i = L; i <= R; i++) sum += arr[i]; // O(n) per query
  return sum;
}

Agar Q queries hain, total time = O(Q × n) — bahut slow jab Q aur n dono bade ho.

JavaScript — Optimal (Prefix Sum)
function buildPrefix(arr) {
  const prefix = new Array(arr.length);
  prefix[0] = arr[0];
  for (let i = 1; i < arr.length; i++) {
    prefix[i] = prefix[i - 1] + arr[i];
  }
  return prefix;
}

function rangeSumQuery(prefix, L, R) {
  if (L === 0) return prefix[R];
  return prefix[R] - prefix[L - 1];
}

Why faster: buildPrefix ek baar O(n) mein sab kuch precompute kar leta hai. Uske baad har query sirf O(1) — bas subtraction. Total: O(n + Q) instead of O(n × Q).

7. Dry Run

📝 arr = [2, 4, 1, 5, 3], query(1, 3)
prefix = [2, 6, 7, 12, 15]
L=1 (not 0) → sum = prefix[3] - prefix[0] = 12 - 2 = 10 ✅ (matches 4+1+5)

StepTimeSpace

Prefix Sum + HashMap (very common interview pattern)

💡 Subarray with sum = k
Jab problem poochhe "subarray with sum = k" (count kitne hain, ya exist karta hai kya), tum prefix sums store karo ek HashMap mein (sum → count/index seen so far). Agar current prefix sum − k already map mein hai, matlab ek subarray mila jiska sum k hai. 
function subarraySumEqualsK(arr, k) {
  const map = new Map();
  map.set(0, 1); // empty prefix
  let sum = 0, count = 0;
  for (let num of arr) {
    sum += num;
    if (map.has(sum - k)) count += map.get(sum - k);
    map.set(sum, (map.get(sum) || 0) + 1);
  }
  return count;
}

2D Prefix Sum

Same idea, but grid ke liye — prefix[r][c] = sum of all elements from (0,0) to (r,c). Rectangle sum query bhi O(1) mein nikal jati hai using inclusion-exclusion:

prefix[r][c] = arr[r][c] + prefix[r-1][c] + prefix[r][c-1] - prefix[r-1][c-1]

When Should I Use It? — Checklist

🎯 Use Prefix Sum when:
  • Multiple range-sum queries on a fixed (unchanging) array
  • Words like "subarray sum", "range sum", "cumulative"
  • 2D grid rectangle sum queries
Agar array baar-baar update ho raha hai (values change ho rahi hain), plain prefix sum kaam nahi karega achhi tarah — tab Fenwick Tree / Segment Tree chahiye (advanced topic).

Common Mistakes

⚠️ Watch Out
  • L === 0 case bhool jaana — tab prefix[L-1] undefined ho jayega.
  • Prefix array ko rebuild karna bhool jana jab original array update ho jaye.
  • Negative numbers wale array mein "sliding window" try karna instead of prefix sum + hashmap — sliding window monotonic sum assume karta hai.

Interview Tips

Jab bhi "subarray" + "sum" dikhe question mein, turant socho: Prefix Sum ya Sliding Window? Agar negative numbers ho sakte hain → Prefix Sum (with HashMap). Agar sab positive/non-negative hain → Sliding Window bhi kaam kar sakta hai.

Interview Questions

Easy Section

Q1. Range Sum Query - ImmutableEasy

Given an array, answer multiple queries of sum(L, R) efficiently.

Input: arr=[1,2,3,4,5], query(1,3) → Output: 9
Hint: Precompute a prefix sum array once; each query becomes O(1) subtraction.
Q2. Find Pivot IndexEasy

Find an index where left-sum equals right-sum.

Input: [1,7,3,6,5,6] → Output: 3
Hint: totalSum - leftSum - arr[i] = rightSum; track running leftSum while looping.
Q3. Running Sum of ArrayEasy

Return the prefix sum array itself.

Input: [1,2,3,4] → Output: [1,3,6,10]
Hint: result[i] = result[i-1] + arr[i], with result[0] = arr[0].
Q4. Number of Ways to Split ArrayEasy

Count split points where left part sum ≥ right part sum.

Input: [10,4,-8,7] → Output: 2
Hint: Compute total sum, walk with a running leftSum, and compare it to (total - leftSum) at each split point.
Q5. Minimum Value to Get Positive Step by Step SumEasy

Find minimum starting value so that cumulative sum never drops below 1.

Input: [-3,2,-3,4,2] → Output: 5
Hint: Track the minimum prefix sum seen; the answer relates directly to how negative that minimum gets.

Medium Section

Q6. Subarray Sum Equals KMedium

Count total subarrays whose sum equals k (array can have negatives).

Input: [1,1,1], k=2 → Output: 2
Hint: If prefixSum[j] - prefixSum[i] = k, subarray (i+1..j) has sum k — track counts of prefix sums seen in a hashmap.
Q7. Continuous Subarray Sum (multiple of k)Medium

Check if array has a subarray of size ≥2 whose sum is a multiple of k.

Input: [23,2,4,6,7], k=6 → Output: true
Hint: Store (prefixSum % k) in a map along with its earliest index; a repeated remainder at distance ≥2 means a valid subarray.
Q8. Product of Array Except SelfMedium

For each index, compute product of all other elements — without division.

Input: [1,2,3,4] → Output: [24,12,8,6]
Hint: Similar to prefix sum but with prefix product from left and suffix product from right; answer[i] = prefixProduct[i-1] * suffixProduct[i+1].
Q9. Maximum Size Subarray Sum Equals kMedium

Find the length of the longest subarray with sum exactly k.

Input: [1,-1,5,-2,3], k=3 → Output: 4
Hint: Map stores prefixSum → earliest index it occurred. If (sum-k) exists in map, length = currentIndex - map.get(sum-k).
Q10. Range Sum Query 2D - ImmutableMedium

Given a matrix, answer multiple rectangle sum queries efficiently.

Input: matrix + query(row1,col1,row2,col2) → Output: sum of that rectangle
Hint: Build 2D prefix using inclusion-exclusion of the 4 corners, then answer each query in O(1).

Hard Section

Q11. Count Number of Nice SubarraysHard

Count subarrays with exactly k odd numbers.

Input: [1,1,2,1,1], k=3 → Output: 2
Hint: Transform: treat odd=1, even=0, then it becomes "subarray sum = k" — apply prefix sum + hashmap directly.
Q12. Maximum Sum of Two Non-Overlapping SubarraysHard

Given lengths L and M, find max sum of two non-overlapping subarrays of those lengths.

Input: [0,6,5,2,2,5,1,9,4], L=1, M=2 → Output: 20
Hint: Build prefix sums for fixed-size windows, then scan keeping a running best of one window while sliding the other.
Q13. Count Subarrays With Median KHard

Count subarrays whose median equals a given value k, in an array of distinct values 1..n.

Input: nums=[3,1,2], k=2 → Output: 3
Hint: Convert to a balance array (+1 for >k, -1 for <k, 0 at k), then use prefix-sum balance counting around k's position.
