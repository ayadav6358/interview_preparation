Two Pointers

Do index variables se array/string traverse karke nested loops avoid karna.

← Prev: Sliding Window Next: Contribution Technique →

1. What is it?

Two Pointers technique mein hum do index variables (pointers) use karte hain array/string ko traverse karne ke liye — usually ek array pass mein hi, bina nested loops ke.

2. Why do we use it?

Bahut saari problems jo brute force mein O(n²) lagti hain (har pair check karke), unhe do pointers cleverly move karke O(n) mein solve kiya ja sakta hai — especially jab array sorted ho.

3. Real-Life Analogy

📝 Two Friends Searching a Bookshelf
Socho ek sorted bookshelf hai (chhoti se badi numbering). Do dost ek saath dhundh rahe hain — ek left se start karta hai, doosra right se. Dono milke bataate hain kya aage badhna hai ya peeche — poori shelf ek akela insaan check karne se kahin fast.

4. Same Direction vs Opposite Direction Pointers

  • Opposite direction: Ek pointer left se, ek right se, beech mein milte hain. Sorted array mein "pair with target sum" jaisi problems ke liye.
  • Same direction: Dono pointers left se start karte hain, alag speed se aage badhte hain (jaise "slow" aur "fast" pointer). Jaise "remove duplicates from sorted array".

5. Visual Diagram — Opposite Direction

arr = [1, 3, 4, 6, 8, 10, 13], target = 14

left=0(1)                    right=6(13)   → sum=14 ✅ found!

Agar sum < target → left++ (need bigger)
Agar sum > target → right-- (need smaller)

6. Code + Explanation

JavaScript — Brute Force (pair with target sum, sorted array)
function pairSumBrute(arr, target) {
  for (let i = 0; i < arr.length; i++) {
    for (let j = i + 1; j < arr.length; j++) {
      if (arr[i] + arr[j] === target) return [i, j];
    }
  }
  return [-1, -1];
}
JavaScript — Optimal Two Pointers (needs sorted array)
function pairSumTwoPointers(arr, target) {
  let left = 0, right = arr.length - 1;
  while (left < right) {
    const sum = arr[left] + arr[right];
    if (sum === target) return [left, right];
    else if (sum < target) left++;   // need a bigger sum
    else right--;                     // need a smaller sum
  }
  return [-1, -1];
}

Why this works: Array sorted hai, isliye agar sum chhota hai to left ko right shift karke bada number lao (sum badhega). Agar sum bada hai to right ko left shift karke chhota number lao (sum ghatega). Har step mein search space se ek element permanently discard hota hai — O(n) total.

Same-Direction Example — Remove Duplicates from Sorted Array

function removeDuplicates(arr) {
  if (arr.length === 0) return 0;
  let slow = 0; // points to last unique element
  for (let fast = 1; fast < arr.length; fast++) {
    if (arr[fast] !== arr[slow]) {
      slow++;
      arr[slow] = arr[fast];
    }
  }
  return slow + 1; // count of unique elements
}

slow hamesha "confirmed unique elements" ke end ko point karta hai. fast aage explore karta hai. Jab naya unique value milti hai, slow ek aage badhkar usse copy kar leta hai.

7. Dry Run

📝 arr = [1,3,4,6,8,10,13], target=14
left=0(1), right=6(13) → sum=14 → found! Return [0,6] in just 1 step (vs brute force checking many pairs).

8. Complexity

Time: O(n) — dono pointers combined se max n steps move karte hain. Space: O(1) — no extra structure needed.

When Should I Use It? — Checklist

🎯 Use Two Pointers when:
  • Array/string is sorted and you need a pair/triplet with some sum condition
  • You need to compare elements from both ends
  • Removing duplicates / partitioning in-place (same-direction pointers)
  • Palindrome checking on strings

Common Mistakes

  • Two pointers try karna on an unsorted array without sorting it first (for the opposite-direction pattern) — sort karna zaroori hai pehle, jo O(n log n) add karega.
  • left < right ki jagah left <= right likh dena — isse same element do baar count ho sakta hai.
  • 3Sum/4Sum jaisi problems mein duplicate triplets skip karna bhool jana.

Interview Tips

Agar array sorted diya hai aur "pair"/"triplet" ka zikr hai, turant Two Pointers bolo. Agar sorted nahi hai, pehle poochho "kya main sort kar sakta hoon?" — ye interviewer ko dikhata hai tumne trade-off socha hai (sorting costs O(n log n) but then enables O(n) two-pointer scan).

Interview Questions

Easy Section

Q1. Two Sum II (Sorted Array)Easy

Find two numbers in a sorted array that add up to a target.

Input: [2,7,11,15], target=9 → Output: [0,1]
Hint: Think about two pointers moving from both ends — move left up if sum too small, right down if too big.
Q2. Valid PalindromeEasy

Check if a string is a palindrome, ignoring non-alphanumeric characters and case.

Input: "A man, a plan, a canal: Panama" → Output: true
Hint: Left pointer at start, right at end, skip non-alphanumeric characters, compare lowercase.
Q3. Reverse String In-PlaceEasy

Reverse an array of characters in-place.

Input: ['h','e','l','l','o'] → Output: ['o','l','l','e','h']
Hint: Swap arr[left] and arr[right], move inward until they meet.
Q4. Move Zeroes to EndEasy

Move all zeroes to the end while maintaining relative order of non-zero elements.

Input: [0,1,0,3,12] → Output: [1,3,12,0,0]
Hint: slow tracks the position for the next non-zero; fast scans and swaps when it finds one.
Q5. Squares of a Sorted ArrayEasy

Given a sorted array (with possible negatives), return sorted squares.

Input: [-4,-1,0,3,10] → Output: [0,1,9,16,100]
Hint: The largest square is always at one of the two ends — fill the result array from the back.

Medium Section

Q6. 3SumMedium

Find all unique triplets that sum to zero.

Input: [-1,0,1,2,-1,-4] → Output: [[-1,-1,2],[-1,0,1]]
Hint: Sort the array, fix one element with a loop, then use two pointers on the rest — skip duplicates.
Q7. Container With Most WaterMedium

Find two lines that together with the x-axis form the container with the most water.

Input: [1,8,6,2,5,4,8,3,7] → Output: 49
Hint: Always move the pointer at the shorter line inward — moving the taller one can only reduce area.
Q8. Sort Colors (Dutch National Flag)Medium

Sort an array of 0s, 1s, and 2s in-place in one pass.

Input: [2,0,2,1,1,0] → Output: [0,0,1,1,2,2]
Hint: Use three pointers — low, mid, high — swap based on the value at mid.
Q9. Remove Nth Node From End of List (two-pointer gap)Medium

Remove the nth node from the end of a linked list in one pass.

Input: 1->2->3->4->5, n=2 → Output: 1->2->3->5
Hint: Move a "fast" pointer n steps ahead first, then move both pointers together until fast reaches the end.
Q10. Boats to Save PeopleMedium

Each boat carries at most 2 people with a weight limit — find minimum boats needed.

Input: people=[3,2,2,1], limit=3 → Output: 3
Hint: Sort, then pair the lightest with the heaviest using two pointers when their sum fits the limit.

Hard Section

Q11. Trapping Rain WaterHard

Given elevation heights, compute total trapped rainwater.

Input: [0,1,0,2,1,0,1,3,2,1,2,1] → Output: 6
Hint: Maintain leftMax and rightMax while moving pointers inward from both ends; trapped water at a position = min(leftMax,rightMax) - height there.
Q12. 4SumHard

Find all unique quadruplets that sum to a target.

Input: [1,0,-1,0,-2,2], target=0 → Output: [[-2,-1,1,2],[-2,0,0,2],[-1,0,0,1]]
Hint: Sort array, fix the first two elements with nested loops, then two-pointer scan for the last two — skip duplicates at every level.
Q13. Minimum Window to Sort (two-pointer boundary detection)Hard

Find the shortest contiguous subarray that, if sorted, makes the whole array sorted.

Input: [2,6,4,8,10,9,15] → Output: length 5 (subarray [6,4,8,10,9])
Hint: Scan from left to find where order breaks, from right similarly, then expand boundaries using min/max of the middle segment.
