Phase 11 · Heap & Priority Queue

Heap and Priority Queue 🏔️

Min/Max Heap implementation, kth largest element, merge k sorted lists — aur interview mein sabse zyada poochhe jaane wale heap problems.

1. Heap & Priority Queue — Concept

1. What is it?

Heap ek special Binary Tree hai (usually array se implement kiya jata hai) jisme ek property maintain hoti hai:

  • Min Heap — har parent apne children se chhota hai. Root = smallest element.
  • Max Heap — har parent apne children se bada hai. Root = largest element.

Priority Queue ek abstract concept hai jisme elements priority ke hisaab se nikalte hain, insertion order se nahi — Heap iska sabse common implementation hai.

2. Why do we need it?

Agar tumhe baar-baar "sabse chhota/bada element nikaalo" chahiye (aur naye elements bhi insert karne hain beech mein), array ko sort rakhna expensive hai (O(n) per insert to maintain order), aur bina sort kiye min/max dhundhna O(n) hai. Heap dono operations — insert aur min/max nikaalna — O(log n) mein deta hai.

3. Real-Life Analogy

📝 Hospital Emergency Room
ER mein patients FIFO order mein treat nahi hote — sabse critical (highest priority) patient pehle dekha jata hai, chahe wo abhi-abhi aaya ho. Ye exactly Priority Queue hai — priority order mein serve karna, arrival order mein nahi.

4. How It Works + Diagram

Heap ek complete binary tree hai — matlab har level bhara hua hai (last level chhod ke, jo left se right fill hota hai). Isko array mein store karna easy hai:

Min Heap (as a tree):
              1
            /   \
           3     5
          / \   /
         8   9 6

Same heap (as an array):  [1, 3, 5, 8, 9, 6]
                            0  1  2  3  4  5  (indices)

For any index i:
  left child index  = 2*i + 1
  right child index = 2*i + 2
  parent index       = Math.floor((i - 1) / 2)

5. Code — Min Heap Implementation

class MinHeap {
  constructor() { this.heap = []; }

  peek() { return this.heap[0]; } // smallest element - O(1)

  insert(val) {
    this.heap.push(val);              // add at the end
    this.bubbleUp(this.heap.length - 1);
  }

  bubbleUp(i) {
    while (i > 0) {
      const parent = Math.floor((i - 1) / 2);
      if (this.heap[parent] <= this.heap[i]) break; // heap property satisfied
      [this.heap[parent], this.heap[i]] = [this.heap[i], this.heap[parent]];
      i = parent;
    }
  }

  extractMin() {
    const min = this.heap[0];
    const last = this.heap.pop();
    if (this.heap.length > 0) {
      this.heap[0] = last;         // move last element to root
      this.bubbleDown(0);
    }
    return min;
  }

  bubbleDown(i) {
    const n = this.heap.length;
    while (true) {
      let smallest = i;
      const left = 2 * i + 1, right = 2 * i + 2;
      if (left < n && this.heap[left] < this.heap[smallest]) smallest = left;
      if (right < n && this.heap[right] < this.heap[smallest]) smallest = right;
      if (smallest === i) break; // heap property satisfied
      [this.heap[i], this.heap[smallest]] = [this.heap[smallest], this.heap[i]];
      i = smallest;
    }
  }
}

Line-by-line: insert naya element end mein daalta hai, phir bubbleUp use karke usko upar move karta hai jab tak parent usse chhota na ho jaye. extractMin root (min) return karta hai, last element ko root par la kar bubbleDown se sahi jagah settle karta hai.

6. Dry Run — Insert into Min Heap [3, 8, 5], insert(1)

📝 bubbleUp trace
heap = [3, 8, 5, 1] (1 pushed at end, index 3)
parent of index 3 = floor((3-1)/2) = 1 → heap[1]=8. Is 8 > 1? Yes → swap → [3, 1, 5, 8]
parent of index 1 = floor((1-1)/2) = 0 → heap[0]=3. Is 3 > 1? Yes → swap → [1, 3, 5, 8]
i=0, loop stops. Final: [1, 3, 5, 8] ✅ (1 is now root, the minimum)

7. Time / Space Complexity

OperationTimeWhy
Peek (min/max)O(1)Always at the root (index 0)
InsertO(log n)bubbleUp travels at most tree height (log n)
Extract Min/MaxO(log n)bubbleDown travels at most tree height
Build heap from arrayO(n)Clever bottom-up construction (not n × log n!)

Space: O(n) — stores all elements.

Why Not Just Use a Sorted Array?

OperationSorted ArrayHeap
Get minO(1)O(1)
Insert (keeping sorted)O(n)O(log n) ⭐
Extract minO(n) (shift array)O(log n) ⭐

Heap trade-off karta hai "poori sorted order" ki jagah "sirf min/max fast milna" — jo bahut sari problems mein hi chahiye hota hai.

8. Key Problem 1: Kth Largest Element

// Using a Min Heap of size k
function findKthLargest(arr, k) {
  const heap = new MinHeap();
  for (const num of arr) {
    heap.insert(num);
    if (heap.heap.length > k) heap.extractMin(); // keep only top k largest
  }
  return heap.peek(); // smallest of the k largest = kth largest overall
}

Why a Min Heap for "Kth LARGEST"? Counter-intuitive but clever: hum sirf top-k largest elements ko heap mein rakhte hain. Jab heap size k se bada ho jaye, sabse chhota (root of min-heap) nikaal dete hain. End mein, heap mein bache k elements sabse bade hain, aur unme se sabse chhota (root) hi kth largest hai.

9. Key Problem 2: Merge K Sorted Lists

Ek Min Heap banao jisme har list ka current head daala jaaye. Baar-baar heap se minimum nikaalo (wo result mein jayega), aur uski list ka next element heap mein daal do. Time: O(N log k) jaha N = total elements, k = number of lists — bahut better than merging lists pairwise one at a time.

10. When Should I Use a Heap? — Checklist

🎯 Use Heap/Priority Queue when:
  • "Kth largest/smallest" ka zikr ho
  • "Top K" elements chahiye
  • Multiple sorted sources ko merge karna hai
  • Task scheduling by priority
  • Median maintain karna hai ek streaming data mein (two heaps trick)

11. Common Mistakes

  • Min Heap aur Max Heap confuse karna — "Kth largest" ke liye Min Heap (of size k) use hota hai, jo counter-intuitive lagta hai.
  • Heap ko "fully sorted" samajhna — sirf root guaranteed min/max hai, baaki elements kisi bhi order mein ho sakte hain.
  • bubbleUp/bubbleDown mein parent/child index formula galat lagana.

12. Interview Tips

"Top K" ya "Kth largest/smallest" sunte hi Heap bolo. Explain karo trade-off: "Poora sort karna O(n log n) hoga, lekin heap se main O(n log k) mein kar sakta hoon jo tab better hai jab k array size se bahut chhota ho."

Interview Questions — Heap

Easy

Q1. Implement a Min HeapEasy
Pattern: Basic implementation

Implement a Min Heap supporting insert, peek, and extractMin operations from scratch using an array.

Example: insert(5), insert(2), insert(8) → peek() = 2

Hint: Use bubbleUp after insert and bubbleDown after extractMin, as shown above.
Q2. Kth Largest Element in a StreamEasy
Pattern: Min Heap of size k

Design a class that continuously maintains the kth largest element as new elements arrive one at a time in a stream.

Example: nums=[4,5,8,2], k=3, add(3) → returns 4

Hint: Maintain a min heap of size k; each new element gets inserted, then extract min if size exceeds k. The root is always the current kth largest.
Q3. Last Stone WeightEasy
Pattern: Max Heap simulation

Given stone weights, repeatedly smash the two heaviest together (difference remains, both destroyed if equal); return the weight of the last stone left, or 0.

Example: stones=[2,7,4,1,8,1] → 1

Hint: Use a max heap. Repeatedly extract the two largest stones and push the difference back in if non-zero.
Q4. K Closest Points to OriginEasy
Pattern: Max Heap of size k

Given an array of points on the X-Y plane, return the k points closest to the origin.

Example: points=[[1,3],[-2,2]], k=1 → [[-2,2]]

Hint: Maintain a max heap (ordered by distance) of size k; if a new point is closer than the heap's current max, swap it in.
Q5. Relative RanksEasy
Pattern: Max Heap with indices

Given scores of athletes, return their ranks — "Gold Medal", "Silver Medal", "Bronze Medal" for top 3, and numeric rank otherwise.

Example: score=[5,4,3,2,1] → ["Gold Medal","Silver Medal","Bronze Medal","4","5"]

Hint: Push (score, original index) pairs into a max heap, pop in order to assign ranks back to original positions.

Medium

Q6. Kth Largest Element in an ArrayMedium
Pattern: Min Heap of size k (or Quickselect)

Find the kth largest element in an unsorted array (not the kth distinct element).

Example: nums=[3,2,1,5,6,4], k=2 → 5

Hint: See findKthLargest code above. Alternatively, Quickselect gives average O(n).
Q7. Top K Frequent ElementsMedium
Pattern: Frequency Map + Heap

Given an integer array, return the k most frequent elements.

Example: nums=[1,1,1,2,2,3], k=2 → [1,2]

Hint: Build a frequency map, then use a min heap of size k (ordered by frequency) to keep only the top k most frequent.
Q8. Task SchedulerMedium
Pattern: Max Heap + cooldown tracking

Given tasks and a cooldown period n between same tasks, find the minimum number of CPU intervals needed to finish all tasks.

Example: tasks=["A","A","A","B","B","B"], n=2 → 8

Hint: Use a max heap ordered by task frequency; process the most frequent available tasks each cycle, tracking a cooldown queue for recently used tasks.
Q9. K Closest Points to Origin (matrix variant) — Kth Smallest Element in a Sorted MatrixMedium
Pattern: Heap over matrix rows

Given an n x n matrix sorted ascending in rows and columns, find the kth smallest element in it.

Example: matrix=[[1,5,9],[10,11,13],[12,13,15]], k=8 → 13

Hint: Push the first element of each row into a min heap with its (row, col); extract min and push the next element from that row, repeat k times.
Q10. Reorganize StringMedium
Pattern: Max Heap greedy rearrangement

Given a string, rearrange its characters so no two adjacent characters are the same; return any valid arrangement or empty string if impossible.

Example: s="aab" → "aba"

Hint: Use a max heap by character frequency; repeatedly place the most frequent remaining character that isn't the same as the previous placed character.

Hard

Q11. Merge K Sorted ListsHard
Pattern: Min Heap across lists

Given k sorted linked lists, merge them into one sorted linked list.

Example: lists=[[1,4,5],[1,3,4],[2,6]] → [1,1,2,3,4,4,5,6]

Hint: Heap of current heads from each list, always extracting the global minimum and advancing that list. See explanation above.
Q12. Find Median from Data StreamHard
Pattern: Two Heaps (Max Heap + Min Heap)

Design a data structure that supports adding numbers and finding the median of all numbers added so far.

Example: addNum(1), addNum(2) → median=1.5; addNum(3) → median=2

Hint: Keep a max heap for the smaller half of numbers, and a min heap for the larger half, balanced in size (differ by at most 1).
Q13. Smallest Range Covering Elements from K ListsHard
Pattern: Min Heap sliding across sorted lists

Given k sorted lists, find the smallest range that includes at least one number from each list.

Example: lists=[[4,10,15,24,26],[0,9,12,20],[5,18,22,30]] → [20,24]

Hint: Use a min heap holding one element from each list plus a tracked current max; each step extract the min, update the range, advance that list's pointer, and update max.
Q14. IPO (Maximize Capital)Hard
Pattern: Two heaps (min heap by capital requirement + max heap by profit)

Given projects with capital requirements and profits, and initial capital, pick up to k projects to maximize final capital.

Example: k=2, w=0, profits=[1,2,3], capital=[0,1,1] → 4

Hint: Sort projects by capital requirement; use a min heap to find affordable ones, push their profits into a max heap, and greedily pick the highest-profit affordable project k times.
