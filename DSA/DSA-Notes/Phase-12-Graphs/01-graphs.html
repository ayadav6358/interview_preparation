Phase 12 · Graphs

Graphs 🗺️

Representation, BFS, DFS, cycle detection, topological sort, Dijkstra's algorithm — sab kuch Hinglish mein, interview-ready.

1. Graphs — Concept

1. What is it?

Graph ek data structure hai jisme nodes (vertices) hote hain jo edges se connected hote hain. Tree bhi ek special (restricted) graph hi hai — jisme koi cycle nahi hoti aur ek hi root hota hai.

2. Why Needed?

Bahut saari real-world problems relationships/connections ke roop mein hoti hain — social networks (friends), maps (roads), dependencies (build order), internet (links). Graph inhe naturally model karta hai aur BFS/DFS/Dijkstra jaise powerful algorithms deta hai in par kaam karne ke liye.

3. Real-Life Analogy

📝 Map of Cities
Cities (vertices) roads (edges) se connected hain. Kuch roads one-way hain (directed edge), kuch dono taraf (undirected). Kuch roads lambi hain, kuch chhoti (weighted edges). Google Maps essentially ek graph problem solve karta hai — shortest path dhundhna.

4. Core Terminology

  • Vertex (Node) — ek point/entity (jaise ek city)
  • Edge — do vertices ke beech connection (jaise ek road)
  • Directed Graph — edges ki ek direction hoti hai (A→B ka matlab B→A nahi)
  • Undirected Graph — edges dono taraf kaam karte hain (A-B matlab B-A bhi)
  • Weighted Graph — har edge ka ek "cost"/"weight" hota hai (jaise distance)

// Building an adjacency list from an edge list
function buildGraph(n, edges) {
  const graph = new Map();
  for (let i = 0; i < n; i++) graph.set(i, []);
  for (const [u, v] of edges) {
    graph.get(u).push(v);
    graph.get(v).push(u); // remove this line for a directed graph
  }
  return graph;
}

6. BFS (Breadth-First Search)

Idea: Level by level explore karo — Queue use karke, jaise Trees ke level order traversal mein dekha.

function bfs(graph, start) {
  const visited = new Set([start]);
  const queue = [start];
  const order = [];

  while (queue.length) {
    const node = queue.shift();
    order.push(node);
    for (const neighbor of graph.get(node)) {
      if (!visited.has(neighbor)) {
        visited.add(neighbor); // mark visited when ADDING to queue, not when processing
        queue.push(neighbor);
      }
    }
  }
  return order;
}
🎯 BFS finds Shortest Path in Unweighted Graphs
Kyunki BFS level-by-level explore karta hai, jab wo pehli baar kisi node tak pahunchta hai, wo guaranteed shortest (fewest edges) path hota hai — is liye "shortest path unweighted graph" sunte hi BFS bolo.

7. DFS (Depth-First Search)

Idea: Ek raste mein jitna gehra ja sakte ho jao, phir backtrack karo. Stack (ya recursion, jo internally stack use karta hai) se implement hota hai.

DFS — Recursive
function dfs(graph, node, visited = new Set(), order = []) {
  visited.add(node);
  order.push(node);
  for (const neighbor of graph.get(node)) {
    if (!visited.has(neighbor)) {
      dfs(graph, neighbor, visited, order);
    }
  }
  return order;
}
DFS — Iterative (using explicit Stack)
function dfsIterative(graph, start) {
  const visited = new Set();
  const stack = [start];
  const order = [];
  while (stack.length) {
    const node = stack.pop();
    if (visited.has(node)) continue;
    visited.add(node);
    order.push(node);
    for (const neighbor of graph.get(node)) {
      if (!visited.has(neighbor)) stack.push(neighbor);
    }
  }
  return order;
}

8. Dry Run — BFS vs DFS

📝 Graph: A-B, A-C, B-D, C-D. Start = A
BFS: Queue=[A]. Visit A, add B,C → order=[A]. Queue=[B,C]. Visit B, add D → order=[A,B]. Visit C (D already added) → order=[A,B,C]. Visit D → order=[A,B,C,D]
DFS (recursive): Visit A → go to B → go to D (B's neighbor) → D's neighbor C not visited → go to C → order=[A,B,D,C]

9. Time / Space Complexity

Both BFS and DFS: Time O(V + E) — har vertex aur edge ek baar visit hota hai. Space: O(V) — visited set + queue/stack/recursion.

BFS vs DFS — When to Use Which

Use CaseUse
Shortest path (unweighted graph)BFS
Level-by-level processingBFS
Explore all paths / connectivity checkEither
Detecting cyclesDFS (usually simpler)
Topological sortDFS (or BFS via Kahn's algorithm)
Memory-constrained (deep but narrow graph)DFS (uses less memory than BFS's wide queue)

10. Cycle Detection

In an Undirected Graph: DFS karo — agar tumhe koi aisa neighbor mile jo already visited hai AND wo tumhara immediate parent nahi hai, cycle hai.

function hasCycleUndirected(graph, n) {
  const visited = new Set();
  function dfs(node, parent) {
    visited.add(node);
    for (const neighbor of graph.get(node)) {
      if (!visited.has(neighbor)) {
        if (dfs(neighbor, node)) return true;
      } else if (neighbor !== parent) {
        return true; // visited neighbor that isn't our parent = cycle!
      }
    }
    return false;
  }
  for (let i = 0; i < n; i++) {
    if (!visited.has(i) && dfs(i, -1)) return true;
  }
  return false;
}

In a Directed Graph: Track a "recursion stack" (nodes currently in the current DFS path) — agar tumhe koi aisa neighbor mile jo recursion stack mein already hai, cycle hai.

function hasCycleDirected(graph, n) {
  const visited = new Set();
  const inStack = new Set(); // nodes in the current DFS path
  function dfs(node) {
    visited.add(node);
    inStack.add(node);
    for (const neighbor of graph.get(node)) {
      if (inStack.has(neighbor)) return true;      // back edge = cycle!
      if (!visited.has(neighbor) && dfs(neighbor)) return true;
    }
    inStack.delete(node); // done exploring this node's path
    return false;
  }
  for (let i = 0; i < n; i++) {
    if (!visited.has(i) && dfs(i)) return true;
  }
  return false;
}

11. Topological Sort

What it is: Ek ordering of vertices in a Directed Acyclic Graph (DAG) jisme har edge u→v ke liye, u order mein v se pehle aaye. Real example: course prerequisites — agar "Math" "Physics" ka prerequisite hai, Math ko pehle padhna hoga.

Kahn's Algorithm (BFS-based)
function topologicalSort(graph, n) {
  const inDegree = new Array(n).fill(0);
  for (const [node, neighbors] of graph) {
    for (const neighbor of neighbors) inDegree[neighbor]++;
  }

  const queue = [];
  for (let i = 0; i < n; i++) if (inDegree[i] === 0) queue.push(i);

  const result = [];
  while (queue.length) {
    const node = queue.shift();
    result.push(node);
    for (const neighbor of graph.get(node)) {
      inDegree[neighbor]--;
      if (inDegree[neighbor] === 0) queue.push(neighbor);
    }
  }
  return result.length === n ? result : []; // empty means a cycle exists!
}

Why this works: "In-degree" matlab kitne edges kisi node mein aa rahe hain (kitne prerequisites hain). Jin nodes ka in-degree 0 hai, unke saare prerequisites poore ho chuke — unhe process karo, aur unke neighbors ka in-degree ghatao. Isse naye "0 in-degree" nodes ban jaate hain, aur process chalta rehta hai.

🎯 Bonus: Cycle Detection via Topological Sort
Agar result mein saare n nodes nahi aaye, matlab koi cycle hai (kuch nodes ka in-degree kabhi 0 nahi hua) — ye Directed Graph cycle detection ka ek aur tarika hai!

12. Shortest Path — Dijkstra's Algorithm

What it solves: Weighted graph mein (non-negative weights) ek source se sabhi nodes tak ka shortest path.

Idea: Greedy approach + Min Heap — hamesha sabse "cheapest so far" node ko process karo, uske through neighbors ke distances update karo agar shorter path mile.

function dijkstra(graph, n, source) {
  // graph: Map
  const dist = new Array(n).fill(Infinity);
  dist[source] = 0;
  const minHeap = new MinHeapWithPriority(); // [distance, node]
  minHeap.insert([0, source]);

  while (!minHeap.isEmpty()) {
    const [currentDist, node] = minHeap.extractMin();
    if (currentDist > dist[node]) continue; // stale entry, skip

    for (const [neighbor, weight] of graph.get(node)) {
      const newDist = currentDist + weight;
      if (newDist < dist[neighbor]) {
        dist[neighbor] = newDist;
        minHeap.insert([newDist, neighbor]);
      }
    }
  }
  return dist;
}

Why a Min Heap: Hume hamesha "abhi tak ka sabse chhota distance wala unvisited node" chahiye — bilkul waisa hi jaisa Heap phase mein "min nikaalo" O(log n) mein hota hai. Ye Dijkstra ko O((V+E) log V) deta hai.

⚠️ Dijkstra Fails with Negative Weights!
Dijkstra ki greedy assumption hai "ek baar shortest distance finalize ho gaya to wo kabhi improve nahi hoga" — negative weights ke saath ye galat ho jata hai. Negative weights ke liye Bellman-Ford algorithm use hota hai (advanced topic).

13. When Should I Use Which Graph Algorithm? — Checklist

🎯 Decision Checklist
  • "Shortest path, unweighted" → BFS
  • "Shortest path, weighted, non-negative" → Dijkstra
  • "Connectivity" / "islands count" / "all paths" → BFS or DFS
  • "Cycle exists?" → DFS (with recursion stack for directed)
  • "Ordering with dependencies" (course schedule, build order) → Topological Sort

14. Common Mistakes

  • Undirected graph cycle detection mein "parent" check bhoolna — har visited neighbor cycle nahi hota, sirf non-parent visited neighbor.
  • BFS mein node ko queue mein daalte waqt visited mark na karna (bajaye process karte waqt) — isse same node multiple baar queue mein aa sakta hai.
  • Directed graph mein "visited" aur "in current recursion stack" ko confuse karna.
  • Dijkstra ko negative weights wale graph par use karna.

15. Interview Tips

Graph problem dekhte hi poochho: "Directed ya undirected? Weighted ya unweighted? Cycle ho sakta hai?" — in answers se turant pata chal jayega BFS, DFS, Dijkstra, ya Topological Sort mein se kaunsa chahiye.

Interview Questions — Graphs

Easy

Q1. Number of IslandsEasy
Pattern: BFS/DFS on grid

Given a 2D grid of '1's (land) and '0's (water), count the number of islands (connected land, 4-directionally).

Example: grid=[["1","1","0"],["0","1","0"],["0","0","1"]] → 2

Hint: Treat the grid as a graph. For each unvisited land cell, run BFS/DFS marking connected land as visited; count starts.
Q2. Find if Path Exists in GraphEasy
Pattern: BFS/DFS connectivity

Given edges of an undirected graph and source/destination, determine if a valid path exists between them.

Example: n=3, edges=[[0,1],[1,2]], source=0, destination=2 → true

Hint: Simple BFS or DFS from source; check if destination is ever visited.
Q3. Flood FillEasy
Pattern: DFS/BFS on grid

Given an image (grid of colors), a starting pixel, and a new color, fill all connected pixels of the same original color.

Example: image=[[1,1,1],[1,1,0],[1,0,1]], sr=1,sc=1, color=2 → [[2,2,2],[2,2,0],[2,0,1]]

Hint: DFS/BFS from the starting pixel, changing color of connected pixels that match the original color.
Q4. Rotting OrangesMedium
Pattern: Multi-source BFS

Given a grid with fresh (1), rotten (2), and empty (0) oranges, find the minimum minutes until no fresh orange remains, or -1 if impossible.

Example: grid=[[2,1,1],[1,1,0],[0,1,1]] → 4

Hint: Start BFS from ALL rotten oranges simultaneously (all in queue initially). Process level by level, tracking minutes to rot all reachable fresh oranges.
Q5. Max Area of IslandEasy
Pattern: DFS/BFS on grid

Given a grid of 0s and 1s, find the maximum area of an island (connected group of 1s, 4-directionally).

Example: grid with one big island of area 6 and small ones of area 1 → 6

Hint: For each unvisited land cell, run DFS/BFS counting connected cells, track the max count seen across all islands.

Medium

Q6. Clone a GraphMedium
Pattern: DFS/BFS + HashMap

Given a reference to a node in a connected undirected graph, return a deep copy (clone) of the graph.

Example: adjList=[[2,4],[1,3],[2,4],[1,3]] → cloned graph with same structure

Hint: Use a map from original node to cloned node to avoid infinite loops on cycles and to wire up neighbor references correctly.
Q7. Course Schedule (can finish all courses?)Medium
Pattern: Cycle detection in directed graph

Given numCourses and prerequisite pairs, determine if it's possible to finish all courses.

Example: numCourses=2, prerequisites=[[1,0]] → true; [[1,0],[0,1]] → false

Hint: Model prerequisites as directed edges; if there's a cycle (see hasCycleDirected above), it's impossible to finish.
Q8. Course Schedule II (return the order)Medium
Pattern: Topological Sort

Return a valid order to finish all courses given the prerequisites, or an empty array if impossible.

Example: numCourses=4, prerequisites=[[1,0],[2,0],[3,1],[3,2]] → [0,1,2,3] (one valid order)

Hint: Use Kahn's algorithm (BFS-based topological sort) — see topologicalSort code above.
Q9. Network Delay TimeMedium
Pattern: Dijkstra's algorithm

Given a network of n nodes and travel times as directed weighted edges, find how long it takes for a signal from node k to reach all nodes (or -1 if impossible).

Example: times=[[2,1,1],[2,3,1],[3,4,1]], n=4, k=2 → 2

Hint: Run Dijkstra from source k; the answer is the maximum value in the resulting distance array (or -1 if any node is unreachable).
Q10. Pacific Atlantic Water FlowMedium
Pattern: Multi-source DFS/BFS from borders

Given a matrix of heights, find cells from which water can flow to both the Pacific and Atlantic oceans (water flows to equal or lower height neighbors).

Example: small heights matrix → list of coordinates reachable from both oceans

Hint: Run BFS/DFS backward from all Pacific-border cells and separately from all Atlantic-border cells (going to equal/higher neighbors); the answer is cells reachable from both.

Hard

Q11. Word LadderHard
Pattern: BFS on implicit word graph

Given a beginWord, endWord, and a word list, find the length of the shortest transformation sequence changing one letter at a time (each intermediate word must be in the list).

Example: beginWord="hit", endWord="cog", wordList=["hot","dot","dog","lot","log","cog"] → 5

Hint: Treat each word as a node; BFS from beginWord, generating neighbors by changing one letter at a time and checking membership in the word set.
Q12. Alien DictionaryHard
Pattern: Topological Sort from constraints

Given a sorted list of words from an alien language's dictionary, derive the order of letters in that alien alphabet.

Example: words=["wrt","wrf","er","ett","rftt"] → "wertf"

Hint: Build a graph of character ordering constraints by comparing adjacent words letter by letter (first differing letter gives an edge), then run topological sort.
Q13. Cheapest Flights Within K StopsHard
Pattern: Modified Dijkstra / Bellman-Ford

Given flights with prices between cities, find the cheapest price from src to dst with at most k stops.

Example: n=4, flights=[[0,1,100],[1,2,100],[2,0,100],[1,3,600],[2,3,200]], src=0, dst=3, k=1 → 700

Hint: Standard Dijkstra doesn't directly track "number of stops" — use Bellman-Ford-style relaxation limited to k+1 iterations, or track stop count in the search state.
Q14. Reconstruct ItineraryHard
Pattern: Eulerian path via Hierholzer's algorithm / DFS with sorted adjacency

Given a list of airline tickets as [from, to] pairs, reconstruct the itinerary starting from "JFK" that uses all tickets exactly once, in lexical order when multiple valid itineraries exist.

Example: tickets=[["MUC","LHR"],["JFK","MUC"],["SFO","SJC"],["LHR","SFO"]] → ["JFK","MUC","LHR","SFO","SJC"]

Hint: Sort destinations for each node, DFS greedily using the smallest lexical destination first, and add nodes to the itinerary post-order (Hierholzer's approach) then reverse.
