Phase 15 · Bit Manipulation

Bit Manipulation — Zero se Interview Tak ⚡

Numbers ke individual bits ko directly manipulate karna — hardware-level fast operations jo O(1) space tricks enable karte hain.

1. What is it?

Computer ke andar har number binary (0s aur 1s) mein store hota hai. Bit Manipulation matlab in individual bits ko directly read/change karna — jo bahut fast operations dete hain (hardware level par direct support hota hai inka).

2. Binary Number System — Quick Refresher

Decimal 13 in binary:
13 = 8 + 4 + 1 = 2³ + 2² + 2⁰

Binary:  1   1   0   1
Position: 3   2   1   0  (powers of 2)

So 13 = 1101 in binary
(13).toString(2)     // "1101" - decimal to binary
parseInt("1101", 2)  // 13 - binary to decimal

3. Real-Life Analogy

📝 Light Switches
Socho 8 light switches ek row mein — har switch ON (1) ya OFF (0) hai. Ye poori row ek 8-bit number represent karti hai. Bit operations "kaunsa switch on/off karo" jaisa direct control dete hain.

4. Why do we need it?

Bit operations normal arithmetic se kaafi zyada fast hote hain (single CPU instruction), aur "constant extra space" wale problems mein (jaise duplicate dhundna bina HashSet ke) bahut useful hote hain.

5. The Core Bitwise Operators

OperatorSymbolRule
AND&1 only if BOTH bits are 1
OR|1 if AT LEAST ONE bit is 1
XOR^1 if bits are DIFFERENT
NOT~Flips every bit
Left Shift<<Shifts bits left, fills with 0 (multiplies by 2 per shift)
Right Shift>>Shifts bits right (divides by 2 per shift)

6. Visual Diagram

  5 = 0101
  3 = 0011
  ----------
5 & 3 = 0001 = 1   (AND: both bits 1 only at position 0)
5 | 3 = 0111 = 7   (OR: at least one bit 1)
5 ^ 3 = 0110 = 6   (XOR: bits differ)

5 << 1 = 1010 = 10  (shift left = multiply by 2)
5 >> 1 = 0010 = 2   (shift right = divide by 2, floor)

7. Important Tricks with Code

Check Even or Odd
function isEven(n) {
  return (n & 1) === 0; // last bit 0 = even, last bit 1 = odd
}

Why this works: Binary mein, sirf last bit decide karta hai number even hai ya odd. n & 1 sirf last bit ko "extract" karta hai.

Check Power of 2
function isPowerOfTwo(n) {
  return n > 0 && (n & (n - 1)) === 0;
}
📝 Why n & (n-1) removes the last set bit
8 = 1000, 7 = 0111 → 8 & 7 = 0000. Power of 2 ka sirf ek hi bit set hota hai, aur n-1 uss bit ko 0 kar deta hai aur baaki sab 1. AND karne par sab 0 ho jata hai — sirf tabhi jab number power of 2 ho.
Set, Clear, Toggle, Check a Bit
function setBit(n, i)    { return n | (1 << i); }   // turn bit i ON
function clearBit(n, i)  { return n & ~(1 << i); }  // turn bit i OFF
function toggleBit(n, i) { return n ^ (1 << i); }   // flip bit i
function checkBit(n, i)  { return (n >> i) & 1; }   // read bit i (0 or 1)

Line-by-line: 1 << i ek "mask" banata hai jisme sirf position i par 1 hai. setBit OR karta hai (force 1). clearBit mask invert karke AND karta hai (force 0). toggleBit XOR karta hai (flip). checkBit right shift karke last bit dekhta hai.

Count Set Bits (Number of 1s) — Brian Kernighan's Algorithm
function countSetBits(n) {
  let count = 0;
  while (n > 0) {
    n = n & (n - 1); // removes the last set bit each time
    count++;
  }
  return count;
}

Why faster than checking each bit: n & (n-1) directly removes the rightmost set bit — loop runs only as many times as there are set bits, not total bits.

Find the Single Number (using XOR)
function singleNumber(arr) {
  let result = 0;
  for (const num of arr) {
    result ^= num; // XOR-ing a number with itself cancels it out (a^a=0)
  }
  return result; // whatever's left is the number that appeared once
}
🎯 XOR's Magic Properties
a ^ a = 0 aur a ^ 0 = a. Isliye agar array mein har number do baar aaye except ek, sab pairs cancel ho jaate hain XOR mein, aur bacha hua answer wahi single number hota hai — O(n) time, O(1) space, bina kisi HashSet ke!

8. Dry Run — countSetBits(12)

📝 12 = 1100 in binary
n=1100: n&(n-1) = 1100 & 1011 = 1000. count=1
n=1000: n&(n-1) = 1000 & 0111 = 0000. count=2
n=0, loop ends. Answer: 2 set bits ✅

9. Complexity

Har bitwise operation: O(1) time (hardware directly support karta hai). Loops over bits (jaise countSetBits): O(log n) relative to value of n, or O(number of set bits) for Brian Kernighan trick.

10. When Should I Use Bit Manipulation? — Checklist

🎯 Checklist
  • Problem mentions "without extra space" alongside numbers appearing multiple times → think XOR
  • "Power of 2" checks
  • Subset generation using bitmask (each bit = include/exclude) — alternative to recursive backtracking for small n (≤20)
  • Space optimization — packing multiple boolean flags into a single integer

Bonus: Bitmask for Subsets

Har number 0 se 2ⁿ-1 tak, uska binary representation ek unique subset represent karta hai — jaha bit i set hai matlab element i included hai.

function allSubsetsBitmask(arr) {
  const n = arr.length;
  const result = [];
  for (let mask = 0; mask < (1 << n); mask++) {
    const subset = [];
    for (let i = 0; i < n; i++) {
      if (mask & (1 << i)) subset.push(arr[i]); // bit i is set
    }
    result.push(subset);
  }
  return result;
}

Common Mistakes

  • & (bitwise AND) aur && (logical AND) ko confuse karna.
  • Negative numbers ke saath bit operations karte waqt two's complement representation samajhe bina confuse ho jaana.
  • Operator precedence bhool jaana — hamesha parentheses use karo: (a & b) === c.

Interview Tips

Jab bhi "constant extra space" ka strong requirement dikhe numbers ke saath, XOR ya bit tricks socho — ye interviewer ko dikhata hai tumhe low-level optimization ka pata hai.

Interview Questions — Bit Manipulation

Easy

Q1. Single NumberEasy
Array mein har number do baar aata hai except ek. Wo dhundo — O(1) extra space.

Example: Input: [4,1,2,1,2] → Output: 4

Hint: XOR all elements — duplicates cancel out to 0, leaving the unique number.

Q2. Counting BitsEasy
0 se n tak har number ke set bits ka count return karo (array).

Example: Input: n = 5 → Output: [0,1,1,2,1,2]

Hint: DP relation — bits(i) = bits(i >> 1) + (i & 1).

Q3. Power of TwoEasy
Diya gaya number power of 2 hai ya nahi, check karo.

Example: Input: n = 16 → Output: true

Hint: A power of 2 has exactly one set bit — check n & (n-1) === 0.

Q4. Missing NumberEasy
Array mein 0 se n tak ke numbers hain, ek missing hai. Wo dhundo.

Example: Input: [3,0,1] → Output: 2

Hint: XOR all indices 0..n with all array values — pairs cancel, missing number remains.

Q5. Get, Set, Clear, Toggle a BitEasy
Ek number ke i-th bit ko get/set/clear/toggle karne ke functions likho.

Example: Input: n=10 (1010), i=0 → setBit → Output: 11 (1011)

Hint: Build a mask with 1 << i, then combine with OR / AND-NOT / XOR depending on the operation.

Medium

Q6. Sum of Two Integers Without + or -Medium
Do integers add karo bina + ya - operator use kiye.

Example: Input: a=2, b=3 → Output: 5

Hint: Use XOR for sum without carry and AND+shift for carry; loop until carry becomes 0.

Q7. Reverse BitsMedium
32-bit unsigned integer ke bits reverse karo.

Example: Input: 00000010...000 → Output: 01000000...000

Hint: Loop 32 times, shift result left and OR in the last bit of n each iteration, then shift n right.

Q8. Generate All Subsets Using BitmaskMedium
Ek array ke saare subsets generate karo bitmask technique se.

Example: Input: [1,2] → Output: [[],[1],[2],[1,2]]

Hint: Loop mask from 0 to 2^n - 1; include arr[i] if bit i of mask is set.

Q9. Two Non-Repeating Numbers (rest appear twice)Medium
Array mein har number do baar aata hai except do numbers. Un dono ko dhundo.

Example: Input: [1,2,1,3,2,5] → Output: [3,5]

Hint: XOR everything to get a^b, find any set bit to partition numbers into two groups, XOR each group.

Q10. Number of 1 Bits (Hamming Weight)Medium
Ek unsigned integer mein kitne '1' bits hain, count karo.

Example: Input: 00000000000000000000000000001011 → Output: 3

Hint: Use Brian Kernighan's n & (n-1) trick to strip the lowest set bit each iteration.

Hard

Q11. Maximum XOR of Two Numbers in an ArrayHard
Array diya hai — do numbers ka maximum possible XOR nikalo.

Example: Input: [3,10,5,25,2,8] → Output: 28

Hint: Build a binary Trie of number bits (MSB first); for each number greedily try to go the opposite bit at each level.

Q12. Bitwise AND of Numbers RangeHard
Do numbers m aur n diye hain (m ≤ n). Range [m, n] ke saare numbers ka bitwise AND nikalo.

Example: Input: m=5, n=7 → Output: 4

Hint: Find the common binary prefix of m and n by right-shifting both until equal, then shift back left.

Q13. Subsets II (with duplicates) Using Bitmask + DedupHard
Array mein duplicates ho sakte hain — saare unique subsets generate karo.

Example: Input: [1,2,2] → Output: [[],[1],[1,2],[1,2,2],[2],[2,2]]

Hint: Sort first, use bitmask enumeration, and skip a mask if it would pick a duplicate element right after skipping its earlier occurrence.

Q14. Minimum Number of Flips to Make a OR b Equal to cHard
Teen integers a, b, c diye hain. Minimum bit flips chahiye a aur b mein taaki (a OR b) == c ho jaye.

Example: Input: a=2, b=6, c=5 → Output: 3

Hint: Compare bit by bit; if c's bit is 1 need at least one of a/b's bit set (0 flips if already, else 1); if c's bit is 0, flip every set bit among a and b at that position.
