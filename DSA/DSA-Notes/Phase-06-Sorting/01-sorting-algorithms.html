Phase 6 · Sorting

Sorting Algorithms

Sorting matlab data ko ek order (ascending/descending) mein arrange karna. Ye itna fundamental hai ki bahut saari optimizations (Binary Search, Two Pointers) sirf tabhi kaam karti hain jab data sorted ho. Chalo 5 important sorting algorithms dekhte hain — simple se lekar efficient tak.

Concept

🔵 Bubble Sort

Idea: Baar-baar adjacent elements ko compare karo, agar galat order mein hain to swap karo. Har pass mein sabse bada element "bubble up" hokar apni sahi jagah (end) chala jata hai.

📝 Analogy
Bulbule paani mein upar aate hain — waise hi bada element har pass mein aage khisak kar end tak pahunch jata hai. 
function bubbleSort(arr) {
  const n = arr.length;
  for (let i = 0; i < n - 1; i++) {
    let swapped = false;
    for (let j = 0; j < n - i - 1; j++) {
      if (arr[j] > arr[j + 1]) {
        [arr[j], arr[j + 1]] = [arr[j + 1], arr[j]]; // swap
        swapped = true;
      }
    }
    if (!swapped) break; // already sorted, stop early
  }
  return arr;
}

Dry Run [5,1,4,2]: Pass1: compare(5,1)→swap→[1,5,4,2]; compare(5,4)→swap→[1,4,5,2]; compare(5,2)→swap→[1,4,2,5]. Pass2: compare(1,4)→no; compare(4,2)→swap→[1,2,4,5]. Sorted!

Time (Best)Time (Worst)Space
O(n) (already sorted, with early-exit)O(n²)O(1)

When to use: Almost never in practice — only for teaching purposes or tiny/near-sorted datasets.

🔵 Selection Sort

Idea: Har pass mein, remaining unsorted part se sabse chhota element dhundo aur usse front mein swap kar do.

function selectionSort(arr) {
  const n = arr.length;
  for (let i = 0; i < n - 1; i++) {
    let minIdx = i;
    for (let j = i + 1; j < n; j++) {
      if (arr[j] < arr[minIdx]) minIdx = j;
    }
    if (minIdx !== i) [arr[i], arr[minIdx]] = [arr[minIdx], arr[i]];
  }
  return arr;
}

Dry Run [5,1,4,2]: i=0: min in [5,1,4,2] is 1 at idx1 → swap → [1,5,4,2]. i=1: min in [5,4,2] is 2 at idx3 → swap → [1,2,4,5]. i=2: min in [4,5] is 4, already in place → [1,2,4,5]. Sorted!

Time (Best)Time (Worst)Space
O(n²) (no early exit possible)O(n²)O(1)

When to use: When minimizing swaps matters (only n swaps total, unlike Bubble Sort) — e.g. when writes are expensive.

🔵 Insertion Sort

Idea: Ek waqt mein ek element lo aur usse already-sorted part mein sahi jagah "insert" kar do — jaise cards ko haath mein sort karna.

📝 Analogy
Playing cards ko haath mein arrange karte waqt, tum ek naya card uthate ho aur already-sorted cards mein uski sahi jagah dhundh kar daal dete ho. 
function insertionSort(arr) {
  for (let i = 1; i < arr.length; i++) {
    let key = arr[i], j = i - 1;
    while (j >= 0 && arr[j] > key) {
      arr[j + 1] = arr[j]; // shift bigger elements right
      j--;
    }
    arr[j + 1] = key; // place key in correct spot
  }
  return arr;
}

Dry Run [5,1,4,2]: i=1(key=1): shift 5 right → [5,5,4,2] → place 1 → [1,5,4,2]. i=2(key=4): shift 5 right → [1,5,5,2] → place 4 → [1,4,5,2]. i=3(key=2): shift 5,4 right → [1,4,5,5]→[1,4,4,5] → place 2 → [1,2,4,5]. Sorted!

Time (Best)Time (Worst)Space
O(n) (already sorted)O(n²)O(1)

When to use: Small arrays, or nearly sorted data (very fast in that case), or online sorting (data arriving one at a time).

🔵 Merge Sort — Divide and Conquer

Idea: Array ko baar-baar aadha karo jab tak single elements na bache (already sorted). Phir unhe sorted order mein merge karte hue wapas jodo.

[5, 1, 4, 2]
   /        \
[5, 1]    [4, 2]
 /  \      /  \
[5] [1]  [4]  [2]
 \  /      \  /
[1,5]     [2,4]      ← merge sorted halves
   \       /
  [1,2,4,5]           ← final merge
function mergeSort(arr) {
  if (arr.length <= 1) return arr;
  const mid = Math.floor(arr.length / 2);
  const left = mergeSort(arr.slice(0, mid));
  const right = mergeSort(arr.slice(mid));
  return merge(left, right);
}

function merge(left, right) {
  const result = [];
  let i = 0, j = 0;
  while (i < left.length && j < right.length) {
    if (left[i] <= right[j]) result.push(left[i++]);
    else result.push(right[j++]);
  }
  while (i < left.length) result.push(left[i++]); // leftover left
  while (j < right.length) result.push(right[j++]); // leftover right
  return result;
}
Time (Best)Time (Worst)Space
O(n log n)O(n log n)O(n)
🎯 Why always O(n log n)?
Merge Sort ka performance input arrangement par depend nahi karta — chahe array already sorted ho ya reverse, hum hamesha isko poora split aur merge karte hain. Ye consistency isse bahut reliable banati hai.

When to use: Jab tumhe guaranteed O(n log n) chahiye (no worst-case surprises), aur jab stability important ho (equal elements apna relative order maintain karte hain). Linked lists sort karne ke liye bhi best hai (no random access needed).

🔵 Quick Sort — Divide and Conquer with a Pivot

Idea: Ek "pivot" element choose karo. Array ko is tarah partition karo ki pivot se chhote elements left mein aayen, bade right mein. Phir dono halves ko recursively sort karo.

function quickSort(arr, low = 0, high = arr.length - 1) {
  if (low < high) {
    const pivotIndex = partition(arr, low, high);
    quickSort(arr, low, pivotIndex - 1);
    quickSort(arr, pivotIndex + 1, high);
  }
  return arr;
}

function partition(arr, low, high) {
  const pivot = arr[high]; // choose last element as pivot
  let i = low - 1; // boundary of "smaller than pivot" region
  for (let j = low; j < high; j++) {
    if (arr[j] < pivot) {
      i++;
      [arr[i], arr[j]] = [arr[j], arr[i]];
    }
  }
  [arr[i + 1], arr[high]] = [arr[high], arr[i + 1]]; // place pivot correctly
  return i + 1;
}

Line-by-line: partition pivot ko last element chunta hai, phir sab chhote elements ko pivot se pehle laata hai swaps ke through. Aakhir mein pivot apni final sorted position mein rakh diya jata hai — usse phir kabhi move nahi karna padta.

Time (Best/Avg)Time (Worst)Space
O(n log n)O(n²) (bad pivot choices, e.g. already sorted array with last-element pivot)O(log n) — recursion stack
⚠️ Worst Case Trap
Agar array already sorted hai aur tum hamesha last element ko pivot chunte ho, har partition sirf ek element ko sahi jagah rakhta hai — O(n²)! Real implementations "random pivot" ya "median-of-three" use karte hain isse avoid karne ke liye.

When to use: Practically fastest average-case sorting for arrays (in-place, cache-friendly) — yehi wajah hai languages ke built-in sort often Quick Sort variants use karte hain (arrays ke liye).

"Stable" ka matlab: agar do elements equal hain, unka relative order sort ke baad wahi rehta hai jo pehle tha. Ye tab important hota hai jab tum multiple keys par sort kar rahe ho (e.g., pehle name se, phir age se).

Common Mistakes

  • Quick Sort ka worst case bhool jaana — hamesha random/median pivot use karo real code mein.
  • Merge Sort mein merge step galat likhna — remaining elements (jab ek array khatam ho jaye) copy karna bhool jaana.
  • In-place vs extra-space sorts ko confuse karna — Merge Sort O(n) extra space leta hai, Quick Sort sirf O(log n) (stack).

Interview Tips

Agar interviewer poochhe "sort karo", clarifying question poochho: "Stability chahiye? Extra space allowed hai? Worst case guarantee chahiye?" — In answers ke hisaab se Merge Sort (guaranteed + stable) ya Quick Sort (fast average, in-place) choose karo.

Interview Questions

Easy Easy

Q1. Implement Bubble SortEasy

Sort an array in-place using bubble sort, with early-exit if no swaps happen in a pass.

Example: arr = [5,1,4,2] → Output: [1,2,4,5]

Hint: Compare adjacent pairs, swap if out of order, repeat n-1 passes.
Q2. Implement Insertion SortEasy

Sort an array in-place using insertion sort.

Example: arr = [5,1,4,2] → Output: [1,2,4,5]

Hint: For each element, shift larger sorted elements right and insert it in the correct spot.
Q3. Sort Colors (Dutch National Flag)Easy

Given an array of only 0s, 1s and 2s, sort it in-place in one pass.

Example: arr = [2,0,2,1,1,0] → Output: [0,0,1,1,2,2]

Hint: Use three pointers — low, mid, high — to partition the array into three regions in a single pass.
Q4. Check if Array is SortedEasy

Return true if the array is sorted in non-decreasing order.

Example: arr = [1,2,2,3] → Output: true

Hint: Single pass, compare each element with the next.
Q5. Merge Two Sorted ArraysEasy

Merge two sorted arrays into one sorted array.

Example: a = [1,3,5], b = [2,4,6] → Output: [1,2,3,4,5,6]

Hint: Two pointers, one per array; pick the smaller each time, then append leftovers.

Medium Medium

Q6. Implement Merge SortMedium

Implement merge sort from scratch (divide and merge).

Example: arr = [5,1,4,2] → Output: [1,2,4,5]

Hint: Recursively split in half, then merge two sorted halves using two pointers.
Q7. Implement Quick SortMedium

Implement quick sort from scratch using the Lomuto partition scheme.

Example: arr = [5,1,4,2] → Output: [1,2,4,5]

Hint: Choose a pivot, partition so smaller elements go left, then recurse on both sides.
Q8. Kth Largest Element in an ArrayMedium

Find the k-th largest element in an unsorted array without fully sorting.

Example: arr = [3,2,1,5,6,4], k = 2 → Output: 5

Hint: Use Quickselect — partition like Quick Sort but recurse only into the relevant half.
Q9. Merge IntervalsMedium

Given a list of intervals, merge all overlapping intervals.

Example: [[1,3],[2,6],[8,10]] → Output: [[1,6],[8,10]]

Hint: Sort intervals by start value first, then sweep through merging overlaps as you go.
Q10. Largest Number Formed From ArrayMedium

Arrange array elements to form the largest possible number (concatenation).

Example: arr = [3,30,34,5,9] → Output: "9534330"

Hint: Use a custom comparator: compare (a+b) vs (b+a) as strings instead of numeric comparison.

Hard Hard

Q11. Count Inversions in an ArrayHard

Count pairs (i, j) where i < j but arr[i] > arr[j].

Example: arr = [2,4,1,3,5] → Output: 3

Hint: Modify Merge Sort's merge step — when an element from the right half is placed before remaining left elements, count those remaining left elements.
Q12. Meeting Rooms II (min rooms required)Hard

Given meeting time intervals, find the minimum number of conference rooms required.

Example: [[0,30],[5,10],[15,20]] → Output: 2

Hint: Sort start times and end times separately, then sweep with two pointers tracking overlapping meetings.
Q13. Median in a Stream of Running IntegersHard

Design a structure that supports adding numbers and finding the median efficiently at any point.

Example: add(1), add(2), median()=1.5, add(3), median()=2

Hint: Maintain two heaps (max-heap for lower half, min-heap for upper half) instead of sorting on every insert.
