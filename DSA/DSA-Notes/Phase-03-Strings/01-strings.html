Phase 3 · Strings

Strings

Immutable character sequences — palindrome, anagram, aur text-specific patterns.

← Prev: Contribution Technique Next: Hashing (Sets & Maps) →

1. What is it?

String characters ka ek sequence hai — jaise "hello". JavaScript mein strings immutable hote hain, matlab ek baar bann jaye to unhe directly modify nahi kar sakte — koi bhi "change" actually ek naya string banata hai.

2. Why do we need to study it separately?

Strings arrays jaisi hi lagti hain (indexed characters), lekin unka immutability wala nature aur text-specific problems (palindrome, anagram, pattern matching) inhe ek alag category bana dete hain jisme specific tricks kaam aate hain.

3. Real-Life Analogy

📝 Beaded Necklace
String ek beaded necklace jaisi hai jisme har bead (character) apni fixed position par hai. Agar tumhe beech ka bead change karna hai, purani necklace tod kar poori nayi banani padegi — waise hi string modify karne par naya string object banta hai.

4. Core Operations + Diagram

str = "hello"
Index:  0   1   2   3   4
Char:   h   e   l   l   o

str.length        → 5
str[1]            → 'e'
str.slice(1, 3)   → "el"
str.indexOf('l')  → 2 (first occurrence)
str.split('')     → ['h','e','l','l','o']

5. Code Examples

Character Frequency Map
function charFrequency(str) {
  const freq = {};
  for (const ch of str) {
    freq[ch] = (freq[ch] || 0) + 1;
  }
  return freq;
}
// charFrequency("apple") → { a:1, p:2, l:1, e:1 }
Palindrome Check — Brute Force
function isPalindromeBrute(str) {
  const reversed = str.split('').reverse().join('');
  return str === reversed; // creates 2 extra strings - O(n) space
}
Palindrome Check — Optimal (Two Pointers)
function isPalindromeOptimal(str) {
  let left = 0, right = str.length - 1;
  while (left < right) {
    if (str[left] !== str[right]) return false;
    left++; right--;
  }
  return true;
}

Why better: Brute force poora reversed string banata hai (extra O(n) space). Two pointers approach koi extra string nahi banata — O(1) space, same O(n) time.

Anagram Check
function isAnagram(str1, str2) {
  if (str1.length !== str2.length) return false;
  const freq = {};
  for (const ch of str1) freq[ch] = (freq[ch] || 0) + 1;
  for (const ch of str2) {
    if (!freq[ch]) return false; // char not present or count exhausted
    freq[ch]--;
  }
  return true;
}

Line-by-line: Pehle str1 ke characters ki frequency count karo. Phir str2 ke har character ke liye frequency ghatao. Agar kisi bhi point par count 0 ya missing mil jaye, matlab anagram nahi hai.

6. Dry Run — Anagram Check

📝 str1="listen", str2="silent"
freq (from listen) = {l:1, i:1, s:1, t:1, e:1, n:1}
Loop str2: s(1→0), i(1→0), l(1→0), e(1→0), n(1→0), t(1→0)
Sab counts exhaust ho gaye bina kisi negative/missing ke → true ✅

7. Complexity

OperationTimeSpace
Palindrome (two-pointer)O(n)O(1)
Anagram checkO(n)O(k) — k = alphabet size
Substring search (naive)O(n×m)O(1)

Substrings vs Subsequences

💡 Don't confuse these!
  • Substring — continuous characters. "abc" ki substrings: "a","ab","abc","b","bc","c" (order + contiguity dono matter).
  • Subsequence — characters same order mein but skip kar sakte ho beech mein se. "abc" ki subsequences include: "a","ac","abc","bc", etc. (contiguity zaroori nahi, order zaroori hai).

Important Patterns Recap for Strings

  • Two Pointers — palindrome check, reverse string
  • Sliding Window — longest substring without repeating characters, anagram search
  • Hashing — frequency counting, anagram grouping

When Should I Use Which Technique?

🎯 Checklist
  • "Is palindrome" / "reverse" → Two Pointers
  • "Longest/shortest substring with condition" → Sliding Window
  • "Anagram" / "character frequency" → Hashing (frequency map)
  • "Subsequence" (non-contiguous) → Usually Recursion/DP

Common Mistakes

  • String ko baar-baar concatenate karna loop mein (result += ch) — immutability ki wajah se ye potentially O(n²) ho sakta hai. Array mein push karke end mein .join('') karna better hai.
  • Substring aur Subsequence ko mix up karna.
  • Case-sensitivity bhool jaana (palindrome/anagram checks mein "Racecar" vs "racecar").

Interview Tips

String problems mein hamesha poochho: "Case-sensitive hai? Spaces/punctuation ignore karne hain?" — ye clarifying questions interviewer ko dikhati hain tum edge cases soch rahe ho.

Interview Questions

Easy Section

Q1. Valid PalindromeEasy

Check if a phrase is a palindrome, ignoring non-alphanumeric characters and case.

Input: "A man, a plan, a canal: Panama" → Output: true
Hint: Two pointers from both ends, skip non-alphanumeric, compare lowercase chars.
Q2. Valid AnagramEasy

Check if two strings are anagrams of each other.

Input: s="anagram", t="nagaram" → Output: true
Hint: Build a frequency map from the first string, then decrement counts using the second.
Q3. First Unique Character in a StringEasy

Find the index of the first non-repeating character.

Input: "leetcode" → Output: 0 ('l')
Hint: Build a frequency map in one pass, then scan again to find the first index with frequency 1.
Q4. Reverse Words in a StringEasy

Reverse the order of words in a string, collapsing extra spaces.

Input: " hello world " → Output: "world hello"
Hint: Split by spaces, filter out empty strings, reverse the array, join with a single space.
Q5. String CompressionEasy

Compress a string using counts of repeated characters (e.g. "aabcccccaaa" → "a2b1c5a3").

Input: "aabcccccaaa" → Output: "a2b1c5a3"
Hint: Walk through the string tracking the current character and a run-length counter, appending to a result array when the character changes.

Medium Section

Q6. Longest Palindromic SubstringMedium

Find the longest palindromic substring in a given string.

Input: "babad" → Output: "bab" (or "aba")
Hint: For each index, try expanding outward assuming it's the center of a palindrome (handle both odd and even length cases).
Q7. Group AnagramsMedium

Group a list of strings into sets of anagrams.

Input: ["eat","tea","tan","ate","nat","bat"] → Output: [["eat","tea","ate"],["tan","nat"],["bat"]]
Hint: For each string, sort its characters to get a canonical key, and group strings with the same key in a HashMap.
Q8. Longest Common PrefixMedium

Find the longest common prefix string among an array of strings.

Input: ["flower","flow","flight"] → Output: "fl"
Hint: Take the first string as a reference prefix, and shrink it while comparing to each subsequent string.
Q9. Check if Two Strings are RotationsMedium

Check if one string is a rotation of another.

Input: s1="waterbottle", s2="erbottlewat" → Output: true
Hint: If s2 is a rotation of s1, s2 must be a substring of (s1+s1).
Q10. Decode StringMedium

Decode an encoded string like "3[a2[c]]" into "accaccacc".

Input: "3[a]2[bc]" → Output: "aaabcbc"
Hint: Use a stack to handle nested brackets — push current string and repeat count when you see '[', pop and build when you see ']'.

Hard Section

Q11. Minimum Window SubstringHard

Find the smallest substring of s containing all characters of t.

Input: s="ADOBECODEBANC", t="ABC" → Output: "BANC"
Hint: Variable sliding window with "need" and "have" frequency maps — expand right until valid, then shrink from left while it stays valid.
Q12. String to Integer (atoi)Hard

Implement atoi to convert a string to a 32-bit signed integer, handling whitespace, signs, and overflow.

Input: " -42" → Output: -42
Hint: Skip leading whitespace, handle an optional sign, read digits while valid, and clamp the result to the 32-bit integer range.
Q13. Regular Expression MatchingHard

Implement regex matching supporting '.' and '*'.

Input: s="aab", p="c*a*b" → Output: true
Hint: Think recursively/DP — dp[i][j] represents whether s[0..i) matches p[0..j); handle '*' by considering zero or more occurrences of the preceding character.
