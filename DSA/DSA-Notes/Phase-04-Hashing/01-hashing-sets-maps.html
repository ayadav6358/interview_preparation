Phase 4 · Hashing

Hashing — Sets and Maps

O(1) average lookup ka jaadu — Set aur Map ka use, aur unse judi common interview patterns.

← Prev: Strings Next: Index →

1. What is it?

Hashing ek technique hai jisme kisi value ko ek "hash function" se guzaar kar ek number (hash) generate kiya jata hai, jo batata hai wo value memory mein kahan store hogi — isse O(1) average lookup milta hai.

  • Set — sirf unique values store karta hai, koi duplicate nahi. (e.g. new Set())
  • Map — key-value pairs store karta hai. (e.g. new Map())

2. Why do we need it?

Array mein "kya ye value exist karti hai?" check karne mein O(n) lagta hai (poora array scan). HashSet/HashMap mein yehi check O(1) average time mein ho jata hai — bahut bada speedup jab baar-baar lookup karna ho.

3. Real-Life Analogy

📝 Library Catalog System
Bina catalog ke, ek specific kitaab dhundhne ke liye poori library scan karni padegi (O(n)). Lekin agar library mein ek digital catalog hai jo seedha book ka shelf number bata de (jaise hash function), tum turant pahunch jaate ho (O(1)). HashMap = library ka digital catalog.

5. Code Examples

Set — Duplicate Detection
function hasDuplicateOptimal(arr) {
  const seen = new Set();
  for (const num of arr) {
    if (seen.has(num)) return true; // O(1) check
    seen.add(num);
  }
  return false;
}

Compare karo isse nested-loop brute force se (O(n²)) — yahan har element ek baar dekhte hain aur Set mein O(1) mein check karte hain → O(n) total.

Map — Two Sum
function twoSum(arr, target) {
  const map = new Map(); // value -> index
  for (let i = 0; i < arr.length; i++) {
    const complement = target - arr[i];
    if (map.has(complement)) return [map.get(complement), i];
    map.set(arr[i], i);
  }
  return [-1, -1];
}
Frequency Map — Most Frequent Element
function mostFrequent(arr) {
  const freq = new Map();
  let maxCount = 0, result = null;
  for (const num of arr) {
    freq.set(num, (freq.get(num) || 0) + 1);
    if (freq.get(num) > maxCount) {
      maxCount = freq.get(num);
      result = num;
    }
  }
  return result;
}

Space: O(n) — har unique element/key ke liye storage lagta hai.

Set vs Map — When to Use Which

Use CaseUse
"Kya ye value already exist karti hai?"Set
"Duplicates remove karo"Set
"Har element ki frequency/count chahiye"Map
"Value se kuch aur associate karna hai" (jaise index, count)Map
"Two Sum jaisa complement lookup"Map

When Should I Use Hashing? — Checklist

🎯 Use Hashing when:
  • Question mein "duplicate", "frequency", "count", "seen before" jaise words hain
  • Fast lookup chahiye (O(1)) instead of scanning array baar-baar
  • Grouping needed (anagrams, same-property items)

Common Mistakes

  • Object {} use karna jab keys numbers ho — JS objects keys ko string mein convert kar dete hain, jo subtle bugs de sakta hai. Map use karo jab key types matter karte hon.
  • HashMap ko O(1) "always" samajhna — worst case (bahut saari collisions) O(n) ho sakta hai, though practically bahut rare hai.
  • Iteration order par depend karna (though JS Maps insertion order maintain karte hain, safe assumption nahi honi chahiye har language mein).

Interview Tips

Jab bhi brute force mein tumhe "check karo ki ye value pehle dekhi thi ya nahi" jaisa kuch nested loop mein karna pade, turant socho — "Set/Map se ye O(1) mein ho sakta hai." Ye ek sabse common optimization pattern hai interviews mein.

Interview Questions

Easy Section

Q1. Contains DuplicateEasy

Check if an array contains any duplicate values.

Input: [1,2,3,1] → Output: true
Hint: Use a hashset to store seen values for O(1) lookup as you scan the array.
Q2. Two SumEasy

Find indices of two numbers that add up to target.

Input: arr=[2,7,11,15], target=9 → Output: [0,1]
Hint: Use a hashmap of value → index, and check for the complement (target - current) at each step.
Q3. Intersection of Two ArraysEasy

Find the unique intersection of two arrays.

Input: [1,2,2,1], [2,2] → Output: [2]
Hint: Put the first array in a Set, then loop the second and check membership.
Q4. Ransom NoteEasy

Check if a ransom note can be constructed using letters from a magazine string (each letter used once).

Input: ransomNote="aa", magazine="aab" → Output: true
Hint: Build a frequency map of the magazine, then decrement counts as you consume letters for the note.
Q5. Isomorphic StringsEasy

Check if two strings are isomorphic (characters from one map consistently to another).

Input: s="egg", t="add" → Output: true
Hint: Use two hashmaps for a bidirectional mapping check (s[i]→t[i] and t[i]→s[i]).

Medium Section

Q6. Group AnagramsMedium

Group a list of strings into sets of anagrams.

Input: ["eat","tea","tan","ate","nat","bat"] → Output: [["eat","tea","ate"],["tan","nat"],["bat"]]
Hint: Use a computed canonical key (sorted characters) as the map key to group matching strings.
Q7. Top K Frequent ElementsMedium

Return the k most frequent elements in an array.

Input: [1,1,1,2,2,3], k=2 → Output: [1,2]
Hint: Build a frequency map, then either sort by frequency or use bucket sort (index = frequency) for O(n).
Q8. Longest Consecutive SequenceMedium

Find the length of the longest consecutive elements sequence, in O(n) time.

Input: [100,4,200,1,3,2] → Output: 4
Hint: Put all numbers in a Set. Only start counting a sequence from a number that has no predecessor (num-1) in the set.
Q9. Subarray Sum Equals KMedium

Count the total number of contiguous subarrays whose sum equals k.

Input: [1,1,1], k=2 → Output: 2
Hint: Track running prefix sum and use a hashmap of prefixSum → count seen so far; check for (sum - k) at each step.
Q10. Subarrays with Equal Number of 0s and 1sMedium

Count subarrays with an equal number of 0s and 1s in a binary array.

Input: [0,1,0,1] → Output: 4
Hint: Convert 0s to -1s, then it becomes "count subarrays with sum 0" — use prefix sum + hashmap.

Hard Section

Q11. First Missing PositiveHard

Find the smallest missing positive integer, ideally in O(n) time and O(1) extra space.

Input: [3,4,-1,1] → Output: 2
Hint: A hashset gives an easy O(n) space solution first; then think about how to reuse the input array itself as the hash structure to cut space to O(1).
Q12. LRU CacheHard

Design a Least Recently Used cache with O(1) get and put operations.

Example: put(1,1), put(2,2), get(1)→1, put(3,3) evicts key 2 (least recently used).
Hint: Combine a Map for O(1) key lookup with a doubly linked list to track usage order — move accessed nodes to front, evict from the back.
Q13. Longest Substring with At Most K Distinct Characters (Hash + Window)Hard

Find the length of the longest substring with at most k distinct characters, and explain the hashmap's role in window shrinking.

Input: "eceba", k=2 → Output: 3 ("ece")
Hint: Maintain a frequency hashmap of characters in the current window; when the map size exceeds k, shrink from the left, removing entries as counts hit zero.
