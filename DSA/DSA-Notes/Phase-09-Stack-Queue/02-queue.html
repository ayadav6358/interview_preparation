Phase 9 · Stack & Queue

Queue

Queue ek FIFO (First In, First Out) data structure hai. BFS, task scheduling, aur "order-preserving processing" wale problems isi par based hote hain.

Concept

1. What is it?

Queue ek data structure hai jo FIFO (First In, First Out) order follow karta hai — jo pehle aaya, wahi pehle jayega.

2. Real-Life Analogy

📝 Ticket Counter Line
Jo pehle line mein khada hua, uska number pehle aata hai. Naye log peeche (rear) judte hain, aur front se serve hoke nikalte hain.

3. Operations + Diagram

Front → [10] [20] [30] ← Rear

Dequeue() → removes 10 (front), returns 10
class Queue {
  constructor() { this.items = []; }
  enqueue(val) { this.items.push(val); }      // O(1)
  dequeue() { return this.items.shift(); }     // O(n) with array! (see note below)
  front() { return this.items[0]; }
  isEmpty() { return this.items.length === 0; }
}
⚠️ Watch Out: Array.shift() is O(n)!
JavaScript array ka .shift() pura array ek position left shift karta hai — O(n). Real efficient queue implementation ke liye ek circular buffer ya linked list (with head/tail pointers) use karna chahiye for true O(1) dequeue.

Application: BFS uses a Queue

💡 Why BFS needs a Queue
Breadth-First Search (Graphs phase) explores level-by-level — sabse pehle discovered node ko sabse pehle process karna hota hai, taki hum "wave by wave" aage badhein. Ye exactly FIFO behavior hai, isliye BFS hamesha Queue use karta hai (jabki DFS Stack/recursion use karta hai).

Circular Queue — Implementation Idea

class CircularQueue {
  constructor(capacity) {
    this.items = new Array(capacity);
    this.capacity = capacity;
    this.front = 0;
    this.size = 0;
  }
  enqueue(val) {
    if (this.size === this.capacity) return false; // full
    const rear = (this.front + this.size) % this.capacity;
    this.items[rear] = val;
    this.size++;
    return true;
  }
  dequeue() {
    if (this.size === 0) return null; // empty
    const val = this.items[this.front];
    this.front = (this.front + 1) % this.capacity;
    this.size--;
    return val;
  }
}

Why circular: Rear index % capacity se wraparound hoti hai — isse freed-up front space reuse ho jaata hai, bina array shift kiye. Har operation O(1) hai.

When Should I Use a Queue?

🎯 Checklist
  • Queue: Order-preserving processing, BFS, task scheduling, rate limiting (sliding window of requests)
  • Deque: Sliding window maximum/minimum (need to remove from both ends)
  • Priority Queue: When you need "process by priority" not "process by arrival order"

Common Mistakes

  • Empty queue par dequeue call karna bina check kiye — crash ya undefined behavior.
  • JavaScript array's .shift() ko O(1) samajhna for queues — it's actually O(n).
  • Queue ko application ke hisaab se select na karna (jaise DFS ke liye Queue use karna) — ye galat traversal order dega.

Interview Tips

Jab "level by level", "shortest path (unweighted)", "order of arrival matters" dikhe — Queue socho. Agar "both ends se insert/remove" chahiye ho (jaise sliding window max), Deque socho. Ye keyword-to-structure mapping interview mein turant decide karne mein madad karti hai.

Interview Questions

Easy Easy

Q1. Implement Queue using Two StacksEasy

Implement a FIFO queue using only two stacks.

Example: enqueue(1), enqueue(2), dequeue() → 1

Hint: Push into stack1 for enqueue; when dequeuing, if stack2 is empty, transfer everything from stack1 into stack2 first.
Q2. Reverse a Queue using StackEasy

Reverse the order of elements in a queue using a stack.

Example: [1,2,3,4] → Output: [4,3,2,1]

Hint: Dequeue everything into a stack (this reverses order), then push everything back into the queue.
Q3. Design Circular QueueEasy

Design a fixed-size circular queue supporting enqueue, dequeue, front, rear, isEmpty, isFull.

Example: capacity=3; enqueue(1); enqueue(2); enqueue(3); enqueue(4) → false (full)

Hint: Track front index and size; compute rear as (front + size) % capacity.
Q4. Number of Recent CallsEasy

Count how many requests happened in the last 3000 ms window, given calls arrive in increasing order.

Example: ping(1), ping(100), ping(3001), ping(3002) → returns 1,2,3,3

Hint: Use a queue to store timestamps; pop from the front while they fall outside the window.
Q5. First Non-Repeating Character in a StreamEasy

As characters arrive one by one, report the first non-repeating character seen so far after each addition.

Example: stream = "aabc" → Output: a, -1, b, b

Hint: Maintain a queue of candidate characters plus a frequency map; pop from the front of the queue while its count > 1.

Medium Medium

Q6. Implement Deque (Double-Ended Queue)Medium

Implement a deque supporting insert/remove from both front and rear in O(1).

Example: pushFront(1), pushBack(2), popFront() → 1

Hint: A doubly linked list with head and tail pointers gives O(1) operations on both ends.
Q7. Rotting Oranges (multi-source BFS)Medium

Given a grid of fresh/rotten oranges, find the minimum minutes until no fresh orange remains.

Example: grid with 2 rotten sources → Output: minutes needed, or -1 if impossible

Hint: Multi-source BFS — enqueue all initially rotten oranges, then spread level by level, tracking time.
Q8. Design a Task SchedulerMedium

Given tasks with a cooldown period between same-type tasks, find the minimum time to finish all tasks.

Example: tasks = ["A","A","A","B","B","B"], n=2 → Output: 8

Hint: Use a max-heap for task frequency and a cooldown queue to track when each task type becomes available again.
Q9. Binary Tree Level Order TraversalMedium

Return the level-by-level values of a binary tree.

Example: tree [3,9,20,null,null,15,7] → Output: [[3],[9,20],[15,7]]

Hint: Standard BFS with a queue, processing one full level (by queue size snapshot) at a time.

Hard Hard

Q10. Sliding Window MaximumHard

Given an array and window size k, return the maximum of each sliding window.

Example: arr = [1,3,-1,-3,5,3,6,7], k=3 → Output: [3,3,5,5,6,7]

Hint: Use a monotonic decreasing deque of indices — the front always holds the current window's max.
Q11. Shortest Path in a Binary Maze (BFS on grid)Hard

Find the shortest path from source to destination in a binary grid where 1 = walkable, 0 = blocked.

Example: 5x5 grid → Output: shortest path length or -1

Hint: BFS from source, since all edges have equal weight (1 step) — BFS guarantees the shortest path first.
Q12. Design Hit CounterHard

Design a hit counter that counts hits received in the past 5 minutes, supporting concurrent-ish timestamps.

Example: hit(1), hit(2), hit(3), getHits(4) → 3, hit(300), getHits(300) → 4, getHits(301) → 3

Hint: Use a queue of timestamps; on getHits, pop from the front while timestamps fall outside the 300-second window.
