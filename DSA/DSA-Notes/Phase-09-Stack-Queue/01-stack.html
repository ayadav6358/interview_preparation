Phase 9 · Stack & Queue

Stack

Stack ek LIFO (Last In, First Out) data structure hai. Bahut saare "matching", "undo", "nested", "monotonic" pattern wale problems isi par based hote hain.

Concept

1. What is it?

Stack ek data structure hai jo LIFO (Last In, First Out) order follow karta hai — jo element sabse aakhri mein daala gaya, wahi sabse pehle nikalega.

2. Real-Life Analogy

📝 Pile of Plates
Plates ka dher — tum hamesha upar se plate uthate ho (jo sabse last mein rakhi gayi thi), aur naya plate bhi upar hi rakhte ho. Neeche wali plate tab tak nahi nikal sakti jab tak upar wali hata na do.

3. Operations + Diagram

Push(10) → Push(20) → Push(30)

Stack (top → bottom):
[30]  ← top (last in)
[20]
[10]

Pop() → removes 30, returns 30
Peek() → looks at top (30) without removing
class Stack {
  constructor() { this.items = []; }
  push(val) { this.items.push(val); }     // O(1)
  pop() { return this.items.pop(); }       // O(1)
  peek() { return this.items[this.items.length - 1]; } // O(1)
  isEmpty() { return this.items.length === 0; }
}

Application 1: Valid Parentheses

function isValid(s) {
  const stack = [];
  const pairs = { ')': '(', ']': '[', '}': '{' };
  for (const ch of s) {
    if (ch === '(' || ch === '[' || ch === '{') {
      stack.push(ch);
    } else {
      if (stack.pop() !== pairs[ch]) return false; // mismatch or empty stack
    }
  }
  return stack.length === 0; // all brackets matched
}

Why Stack works here: Har opening bracket ko "remember" karna padta hai until uska matching closing bracket aaye — aur sabse recent opening bracket hi sabse pehle close hona chahiye (nested structure). Ye exactly LIFO behavior hai.

📝 Dry Run: "([)]"
'(' → push → [(]
'[' → push → [(,[]
')' → pop → '[' ≠ expected '(' → return false ❌ (correctly invalid!)

Application 2: Next Greater Element (Monotonic Stack)

function nextGreaterElement(arr) {
  const result = new Array(arr.length).fill(-1);
  const stack = []; // stores indices, values are in decreasing order

  for (let i = 0; i < arr.length; i++) {
    while (stack.length && arr[stack[stack.length - 1]] < arr[i]) {
      const idx = stack.pop();
      result[idx] = arr[i]; // arr[i] is the "next greater" for this popped index
    }
    stack.push(i);
  }
  return result;
}

Why faster than brute force: Brute force checks every element against every future element — O(n²). The monotonic stack ensures each index is pushed and popped at most once — O(n) total.

When Should I Use a Stack?

🎯 Checklist
  • "Undo" functionality, matching/nesting (brackets, HTML tags)
  • DFS, expression evaluation
  • "Next greater/smaller element" style problems (monotonic stack)

Common Mistakes

  • Empty stack par pop/peek call karna bina check kiye — crash ya undefined behavior.
  • Monotonic stack mein galat comparison (< vs <=) use karna — duplicates ke handling mein bug aa sakta hai.
  • Stack ko application ke hisaab se select na karna (jaise BFS ke liye Stack use karna) — ye galat traversal order dega.

Interview Tips

Jab bhi "matching", "nested", "balanced", "undo" jaisa kuch dikhe — Stack socho. Monotonic stack pattern "next greater/smaller", "daily temperatures", "histogram" jaisे problems mein turant recognize karo — ye keyword-to-structure mapping interview mein turant decide karne mein madad karti hai.

Interview Questions

Easy Easy

Q1. Valid ParenthesesEasy

Given a string of brackets ( ) [ ] { }, determine if it's valid (properly matched and nested).

Example: "()[]{}" → Output: true, "(]" → Output: false

Hint: Push opening brackets; on a closing bracket, pop and check it matches.
Q2. Min Stack (get minimum in O(1))Easy

Design a stack that supports push, pop, top, and retrieving the minimum element, all in O(1).

Example: push(-2), push(0), push(-3), getMin()→-3, pop(), getMin()→-2

Hint: Maintain a second stack that tracks the minimum at each level, pushed/popped alongside the main stack.
Q3. Implement Stack using Array vs Linked ListEasy

Implement a stack using both an array and a singly linked list, comparing trade-offs.

Example: push(1), push(2), pop() → 2

Hint: Array-based: push/pop at the end. Linked-list-based: push/pop at the head.
Q4. Remove All Adjacent Duplicates in a StringEasy

Repeatedly remove adjacent duplicate characters until none remain.

Example: "abbaca" → Output: "ca"

Hint: Push characters onto a stack; if the top equals the current character, pop instead of pushing.
Q5. Implement Two Stacks in One ArrayEasy

Implement two stacks using a single array efficiently.

Example: stack1 grows from left, stack2 grows from right

Hint: Grow one stack from index 0 forward and the other from the last index backward.

Medium Medium

Q6. Next Greater ElementMedium

For each element, find the next element to its right that's greater than it.

Example: [2,1,2,4,3] → Output: [4,2,4,-1,-1]

Hint: Use a monotonic decreasing stack of indices, popping whenever a bigger value is found.
Q7. Daily TemperaturesMedium

Given daily temperatures, return how many days you'd have to wait for a warmer temperature.

Example: [73,74,75,71,69,72,76,73] → Output: [1,1,4,2,1,1,0,0]

Hint: Same monotonic stack pattern as Next Greater Element, but store index differences instead of values.
Q8. Evaluate Reverse Polish NotationMedium

Evaluate an arithmetic expression given in postfix (Reverse Polish) notation.

Example: ["2","1","+","3","*"] → Output: 9

Hint: Push numbers onto a stack; on an operator, pop two numbers, apply the operator, push the result.
Q9. Decode StringMedium

Decode a string with nested k[encoded_string] pattern.

Example: "3[a2[c]]" → Output: "accaccacc"

Hint: Use a stack to save (count, partial string) pairs whenever you hit "[", and build the repeated string on "]".

Hard Hard

Q10. Largest Rectangle in HistogramHard

Given bar heights of a histogram, find the area of the largest rectangle that fits.

Example: heights = [2,1,5,6,2,3] → Output: 10

Hint: Use a monotonic increasing stack of indices; when a smaller bar appears, pop and compute area using popped height times width to current index.
Q11. Trapping Rain Water (stack approach)Hard

Given elevation heights, compute how much water can be trapped after raining.

Example: [0,1,0,2,1,0,1,3,2,1,2,1] → Output: 6

Hint: Maintain a decreasing stack of indices; when a taller bar comes, pop and calculate trapped water using the bounded width and height difference.
Q12. Basic Calculator (with parentheses)Hard

Evaluate a string expression containing +, -, parentheses, and spaces.

Example: "(1+(4+5+2)-3)+(6+8)" → Output: 23

Hint: Use a stack to save the running result and sign whenever you enter a new "(" scope, restoring on ")".
