    Senior / Tech Lead Interview Prep

    🎯 Goal: interview-ready for Senior / Tech Lead roles in 4–6 months

    How to use this site

    Work through topics roughly in the order below — System Design → TypeScript → React/Next.js → Node.js → Testing → Cloud/DevOps → Observability/Security → Python → AI Integration → Soft Skills/Leadership. Each chapter has internals, code, interview Q&A (hidden, test yourself first), and a practice assignment. Mark chapters done as you go — your progress is saved in this browser. Check the Roadmap for a week-by-week schedule.

    Topics 11–15 (Web/React/Node/Python Fundamentals + Machine Learning & AI) are supplementary, fundamentals-level courses — use them as a refresher before the matching advanced topic if you ever feel shaky on basics, not as something to do strictly last. Machine Learning & AI is a standalone deep-dive into ML/DL from first principles, separate from the applied "AI Integration" topic above.

    1. System Design — the backbone of every senior/lead interview.
    2. TypeScript Advanced — sharpen the language you already use daily.

    7. Observability & Security — logging, tracing, OWASP, incident response.
    8. Python Intermediate — enough to be dangerous in FastAPI/ML-adjacent teams.
    9. AI Integration — LLM APIs, RAG, agents — increasingly a senior-interview topic.
    10. Soft Skills & Leadership — the part that actually makes you a lead.
