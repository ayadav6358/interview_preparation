OSI, TCP/IP & How the Web Works

Basic Networking

Concept (What & Why)

Data layers se hokar jaata hai. Interview ka sabse common sawal: 'Browser mein URL daalne par kya hota hai?'

Definition Deep-Dive

QuestionAnswer
Simple definitionLayered rules that let any two computers exchange data; each layer has one job.
Technical definitionThe OSI model (7 layers) and TCP/IP (4 layers) describe encapsulation: application data is wrapped in TCP/UDP segments, IP packets, and link-layer frames, then unwrapped at the destination.
Why does it exist?Divides a complex problem so devices from different vendors interoperate.
What happens without it?Incompatible proprietary networks.
When to useReasoning and troubleshooting.
When NOT to useN/A
Real-world analogyPostal system: letter (application), envelope with address (IP), truck (link).

Diagram & Internal Working

OSI (7)                TCP/IP (4)        Example
7 Application  ┐
6 Presentation ├──>   Application        HTTP, DNS, SSH, TLS
5 Session      ┘
4 Transport    ──>    Transport          TCP / UDP (ports)
3 Network      ──>    Internet           IP, ICMP, routing
2 Data Link    ┐
1 Physical     ┘──>   Link               Ethernet, WiFi, MAC

URL -> DNS -> TCP handshake -> TLS handshake -> HTTP request -> response -> render

How it works internally (diagram explained)

The application produces data > TCP adds ports and sequence numbers (segment) > IP adds source/destination IP (packet) > Ethernet adds MAC addresses (frame) > bits on the wire. Each router reads only the IP header and forwards; the receiver reverses the process.

Real-World Example

L7 HTTP GET /  ->  L4 TCP :443  ->  L3 IP 10.0.1.5 -> 203.0.113.10  ->  L2 Ethernet frame  ->  L1 wire/wifi

A request from a laptop to a web server is encapsulated at each layer. The router forwards based on IP; the switch on MAC; the load balancer on port (L4) or HTTP path (L7).

Install / Setup

# nothing to install; tools: sudo apt install dnsutils curl traceroute -y

Practical Examples

Trace the whole journey of a URL

dig +short example.com                    # 1. DNS -> IP
traceroute example.com                    # 2. path of routers
curl -v https://example.com 2>&1 | head -40   # 3. TCP, TLS, HTTP details
curl -w 'dns:%{time_namelookup} connect:%{time_connect} tls:%{time_appconnect} total:%{time_total}\n' -o /dev/null -s https://example.com

Hands-On Lab

Lab Goal

See layers in real traffic.

Prerequisites

  • Linux/WSL with tcpdump or Wireshark
  • curl

Step 1

sudo tcpdump -i any -nn -c 15 port 80 or port 443

Starts capture in one terminal.

Step 2

curl -s http://example.com >/dev/null

Generates traffic.

Step 3

Read the output

You will see SYN, SYN-ACK, ACK (TCP layer), then HTTP data. IP addresses appear at layer 3.

Real-World Problems & Fixes (Troubleshooting)

Problem: Website slow only for some users
Cause: DNS resolves to far region / no CDN
Fix: Use curl -w timing to find the slow phase; add CDN, GeoDNS.

Hinglish Explanation

Har layer ka ek kaam hai. Router IP dekhta hai (L3), switch MAC (L2), load balancer port (L4) ya HTTP (L7). Problem kaunsi layer par hai ye pehchano.

Interview Questions

Q1. What happens when you type google.com in browser?

Browser cache -> DNS resolution (recursive resolver -> root -> TLD -> authoritative) -> TCP 3-way handshake -> TLS handshake -> HTTP GET -> server response -> browser renders, loading more resources.

Q2. TCP vs UDP?

TCP: reliable, ordered, connection-oriented (web, SSH). UDP: connectionless, faster, no guarantee (DNS, video, QUIC).

Q3. Explain TCP 3-way handshake.

SYN -> SYN-ACK -> ACK. Connection closes with FIN/ACK exchanges.

Q4. Which layer do load balancers L4 and L7 work at?

L4 at transport (IP+port), L7 at application (HTTP path/header based).

Q5. What is MTU?

Max packet size on a link (1500 typical). Mismatch causes fragmentation or dropped large packets.

Q6. At which layer do firewall, WAF and LB operate?

Classic firewalls L3/L4, WAF L7, load balancers L4 (NLB) or L7 (ALB).

Why: Mapping tools to layers.

Real-world example: ALB path routing = L7.
