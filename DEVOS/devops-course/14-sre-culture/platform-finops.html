Platform Engineering, FinOps & Career

Advanced SRE, Reliability & DevOps Culture

Concept (What & Why)

Internal Developer Platform (golden paths), cost governance aur DevOps career path aur certifications.

Definition Deep-Dive

QuestionAnswer
Simple definitionPlatform engineering builds easy self-service tools for developers; FinOps keeps cloud spending under control.
Technical definitionPlatform engineering delivers an internal developer platform (IDP) with golden paths, templates, catalogs and guardrails; FinOps applies visibility, allocation, optimisation and governance to cloud costs through collaboration between engineering, finance and product.
Why does it exist?Reduce cognitive load and cost waste at scale.
What happens without it?Every team reinvents pipelines/infra and nobody owns spend.
When to useOrganisations with many teams/services.
When NOT to useBuilding a platform nobody asked for.
Real-world analogyA company kitchen with ready recipes and a budget dashboard.

Diagram & Internal Working

Developers -> Portal (Backstage) -> templates/golden path -> auto CI/CD + infra + monitoring
Platform team = product team serving internal developers
FinOps: tag -> allocate -> optimize (rightsizing, savings plans, spot) -> budget alerts

How it works internally (diagram explained)

A developer requests a new service via a portal template (Backstage) > scaffolder creates the repo, CI pipeline, Helm chart, monitoring dashboards and cloud resources through Terraform/Crossplane > guardrails via policy as code apply automatically > costs are tagged by team/service and shown in dashboards > budgets/anomaly alerts notify owners.

Install / Setup

npx @backstage/create-app@latest    # Backstage portal

Configuration Explained Line by Line

Cost tagging and budget example explained

# Terraform: consistent tags for cost allocation
provider "aws" {
  default_tags { tags = { team = "payments", service = "checkout", env = "prod", cost-center = "cc-1042" } }
}
# CLI: monthly budget with alert at 80%
aws budgets create-budget --account-id 123456789012 --budget file://budget.json --notifications-with-subscribers file://notif.json
LineMeaning / WHY it exists
default_tagsEvery resource gets team/service tags, enabling cost allocation.
cost-centerLinks spend to finance codes.
budgetsAlerts owners before overspend; anomaly detection catches surprises.

Hands-On Lab

Lab Goal

Find cost waste in an AWS account (read-only).

Prerequisites

  • AWS CLI with read access to Cost Explorer/EC2

Step 1

aws ce get-cost-and-usage --time-period Start=2026-08-01,End=2026-09-01 --granularity MONTHLY --metrics UnblendedCost --group-by Type=DIMENSION,Key=SERVICE

Cost by service (adjust dates).

Step 2

aws ec2 describe-volumes --filters Name=status,Values=available --query 'Volumes[].{ID:VolumeId,Size:Size}'

Unattached EBS volumes are waste.

Step 3

aws ec2 describe-addresses --query 'Addresses[?AssociationId==null]'

Unassociated Elastic IPs cost money.

Interview Questions

Q1. What is platform engineering?

Building self-service internal platforms to improve developer productivity.

Q2. What is FinOps?

Practice of cloud financial accountability across engineering and finance.

Q3. DevOps vs SRE vs Platform?

DevOps culture/practices; SRE applies software engineering to reliability with SLOs; Platform builds internal products.

Q4. How do you measure DevOps success?

DORA metrics.

Q5. What is toil?

Manual, repetitive, automatable work that scales with service growth; SRE aims to keep it under 50%.

Q6. How to reduce cloud cost without hurting reliability?

Start with waste (idle/unattached), rightsize using utilisation data, commit for baseline, Spot for fault-tolerant workloads, keep SLOs and redundancy for critical paths, and track savings.

Why: FinOps judgement.

Real-world example: Dev environments scheduled off at night.
