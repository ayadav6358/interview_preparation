AWS Automation with boto3

Intermediate Python & Automation

Concept (What & Why)

boto3 se AWS resources programmatically manage karo: cost saving scripts, backups, audits.

Definition Deep-Dive

QuestionAnswer
Simple definitionboto3 lets Python control AWS: create, list, stop, delete resources.
Technical definitionboto3 is the AWS SDK: it signs API requests (SigV4) using credentials from the default provider chain (env, profile/SSO, container/instance role) and returns Python dicts.
Why does it exist?Automate cloud operations.
What happens without it?Console clicks.
When to useInventory, cleanup, tagging, backups.
When NOT to useLong-lived access keys.
Real-world analogyA remote control for the whole AWS console.

Diagram & Internal Working

script --(credentials: role/profile)--> boto3 client --> AWS API (EC2, S3, IAM...)

How it works internally (diagram explained)

boto3.client('ec2') loads the service model, resolves credentials through the provider chain, signs each HTTPS request with SigV4 and parses the JSON/XML response. Paginators call the API repeatedly with the continuation token. Retries with backoff handle throttling.

Install / Setup

pip install boto3
aws configure   # or use SSO / IAM role; NEVER hard-code keys

Configuration Explained Line by Line

boto3 snippet explained

import boto3
from botocore.config import Config

cfg = Config(retries={"max_attempts": 10, "mode": "standard"})
s3 = boto3.client("s3", config=cfg)
for page in s3.get_paginator("list_objects_v2").paginate(Bucket="my-bucket"):
    for obj in page.get("Contents", []):
        print(obj["Key"])
LineMeaning / WHY it exists
Config(retries=...)Automatic retries with backoff for throttling.
get_paginatorIterates all pages instead of only the first 1000 keys.
page.get('Contents', [])Empty buckets have no Contents key.

Practical Examples

Stop dev instances outside office hours

import boto3
ec2 = boto3.client("ec2", region_name="ap-south-1")
resp = ec2.describe_instances(Filters=[
    {"Name": "tag:Env", "Values": ["dev"]},
    {"Name": "instance-state-name", "Values": ["running"]}])
ids = [i["InstanceId"] for r in resp["Reservations"] for i in r["Instances"]]
if ids:
    ec2.stop_instances(InstanceIds=ids)
    print("stopped", ids)

Find public S3 buckets

s3 = boto3.client("s3")
for b in s3.list_buckets()["Buckets"]:
    try:
        st = s3.get_public_access_block(Bucket=b["Name"])["PublicAccessBlockConfiguration"]
        if not all(st.values()): print("REVIEW", b["Name"])
    except Exception:
        print("NO BLOCK", b["Name"])

Real-World Problems & Fixes (Troubleshooting)

Problem: Throttling errors (RequestLimitExceeded)
Cause: Too many API calls
Fix: Use paginators + exponential backoff (botocore.config.Config(retries={'max_attempts':10,'mode':'adaptive'})).
Problem: Script stopped prod by mistake
Cause: No filter/dry-run
Fix: Use tags filter, DryRun=True, and confirm prompt.

Best Practices

Security

  • Least-privilege IAM roles; short-lived credentials.

Reliability

  • Retries, pagination, dry-run.

Common Mistakes

Developer mistakes

  • Ignoring pagination.
  • Hard-coded region and keys.

Hinglish Explanation

boto3 mein credentials role/SSO se lo, code mein keys mat likho, aur list calls par paginator lagao.

Memory Tricks

ConceptMemory trick
Credential chainEnv > Profile/SSO > Role

Version / Environment Notes

  • Use boto3.client; resource is not receiving new features. Check botocore docs for API names; regions/services vary by account.

Interview Questions

Q1. client vs resource in boto3?

client low-level 1:1 with API; resource higher-level OOP (being deprecated).

Q2. How to handle pagination?

client.get_paginator('describe_instances').

Q3. How do you authenticate boto3 on EC2?

Instance profile IAM role; no keys stored.

Q4. How to test automation safely?

DryRun flag, moto for mocks, non-prod account.

Q5. What is idempotency in automation?

Running multiple times yields same end state.

Q6. How to safely run destructive AWS scripts?

Dry-run default, allow-list by tag, small IAM role, snapshots, confirmation, logs and peer review.

Why: Blast radius control.

Real-world example: Only env=dev tagged resources.
