Basic Python & Automation

Concept (What & Why)

Variables, lists, dicts, functions, files, virtualenv. JSON/YAML parsing DevOps ka daily kaam hai.

Definition Deep-Dive

QuestionAnswer
Simple definitionPython is an easy programming language used to automate tasks.
Technical definitionPython is a dynamically typed, interpreted language with rich standard library (os, subprocess, json, logging, pathlib) and a large package ecosystem via PyPI.
Why does it exist?Readable automation with strong libraries.
What happens without it?Fragile shell scripts for complex logic.
When to useAutomation, tooling, glue code.
When NOT to useVery performance-critical tools (consider Go).
Real-world analogyA Swiss army knife for operations.

Diagram & Internal Working

project/
├── .venv/            (isolated deps)
├── requirements.txt
└── main.py
python -m venv .venv -> activate -> pip install -r requirements.txt

How it works internally (diagram explained)

Python compiles source to bytecode and runs it in the interpreter. import finds modules on sys.path (including the active venv's site-packages). subprocess.run starts a child process; exceptions propagate up the call stack until caught.

# Windows: winget install Python.Python.3.12 ; Ubuntu: sudo apt install python3 python3-venv python3-pip -y
python3 -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install requests pyyaml boto3

Configuration Explained Line by Line

Small utility script explained

import json, logging, subprocess, sys

logging.basicConfig(level=logging.INFO)

def disk_usage_percent(path="/"):
    out = subprocess.run(["df", path, "--output=pcent"], capture_output=True, text=True, check=True).stdout
    return int(out.splitlines()[1].strip().rstrip("%"))

if __name__ == "__main__":
    pct = disk_usage_percent()
    logging.info("disk usage %s%%", pct)
    sys.exit(1 if pct > 80 else 0)
LineMeaning / WHY it exists
subprocess.run([...], check=True)List form avoids shell injection; check=True raises on failure.
capture_output/textCaptures stdout as a string.
loggingStructured levels instead of print.
sys.exit(1 if pct > 80 else 0)Exit code lets cron/CI detect a problem.

Practical Examples

Read YAML/JSON, write report

import json, yaml
with open("config.yaml") as f:
    cfg = yaml.safe_load(f)
servers = cfg["servers"]
report = {s["name"]: s["port"] for s in servers if s.get("enabled")}
print(json.dumps(report, indent=2))

Functions and error handling

def read_file(path):
    try:
        with open(path) as f:
            return f.read()
    except FileNotFoundError:
        print(f"missing: {path}")
        return None

Creates and activates an isolated environment (Windows: .venv\Scripts\activate).

Step 2

pip install requests && python -c "import requests;print(requests.get('https://api.github.com', timeout=10).status_code)"

Step 3

echo '{"a":[1,2]}' | python -m json.tool

Pretty-prints JSON.

Real-World Problems & Fixes (Troubleshooting)

Problem: 'ModuleNotFoundError' on server
Cause: Packages installed globally on another interpreter
Fix: Use venv, pin deps in requirements.txt, run python -m pip.
Problem: Script works locally, fails in CI
Cause: Different Python version
Fix: Pin version in CI (actions/setup-python), use pyproject/lockfile.

Interview Questions

Q1. List vs tuple vs set vs dict?

List ordered mutable; tuple immutable; set unique unordered; dict key-value.

Q2. What is a virtualenv?

Isolated environment with its own packages.

Q3. yaml.load vs safe_load?

safe_load avoids arbitrary code execution; always use it.

Q4. What is a context manager (with)?

Ensures cleanup (closing files) even on errors.

Q5. How to handle secrets in scripts?

Env vars / secret manager, never hard-code.

Q6. Why avoid shell=True?

It passes the string through a shell, enabling command injection and quoting bugs; pass a list instead.

Why: Security.

Real-world example: User-supplied filenames.
