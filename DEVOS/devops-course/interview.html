Linux

Difference between hard link and soft link? (Filesystem & Basic Commands)

Hard link points to the same inode (survives deletion of original, cannot cross filesystems, not for directories). Soft link is a separate file holding a path; breaks if target is removed.

What is /proc? (Filesystem & Basic Commands)

Virtual filesystem exposing kernel and process info in memory, e.g. /proc/cpuinfo, /proc/<pid>/status. No disk usage.

How to find a file bigger than 100MB modified in last 2 days? (Filesystem & Basic Commands)

find / -type f -size +100M -mtime -2 2>/dev/null

What does 2>&1 mean? (Filesystem & Basic Commands)

Redirect file descriptor 2 (stderr) to where fd 1 (stdout) currently points.

Difference between > and >>? (Filesystem & Basic Commands)

> truncates and writes, >> appends.

What is an inode? (Filesystem & Basic Commands)

Metadata structure storing file attributes (owner, perms, size, block pointers) but not the filename. 'No space left' can occur due to inode exhaustion (df -i).

Find and delete logs older than 30 days safely. (Filesystem & Basic Commands)

Preview with find /var/log/app -name '*.log' -mtime +30 -print, then add -delete, or use logrotate.

Why: Safe operations.

Real-world example: Never run delete first.

What does chmod 644 mean? (Users, Groups & Permissions)

Owner rw-, group r--, others r--.

What is sticky bit? (Users, Groups & Permissions)

On directories, only file owner (or dir owner/root) can delete files - used in /tmp.

Difference between su and sudo? (Users, Groups & Permissions)

su switches user with target's password; sudo runs a command as another user using your own credentials per /etc/sudoers policy, with audit log.

Where are users and passwords stored? (Users, Groups & Permissions)

/etc/passwd (accounts), /etc/shadow (hashed passwords, root-only), /etc/group.

What is setuid? (Users, Groups & Permissions)

Executable runs with the file owner's privileges (e.g. passwd). Risky if misused.

How to give a user access to only one command via sudo? (Users, Groups & Permissions)

Edit with visudo: deploy ALL=(ALL) NOPASSWD: /bin/systemctl restart myapp.

What does umask do? (Users, Groups & Permissions)

It subtracts permission bits from newly created files: umask 022 gives files 644 and directories 755.

Why: Default permissions.

Real-world example: umask 027 for private services.

Difference between SIGTERM and SIGKILL? (Processes, Signals & systemd)

SIGTERM can be caught for graceful shutdown; SIGKILL cannot be caught/ignored, kernel terminates immediately.

What is a zombie vs orphan process? (Processes, Signals & systemd)

Zombie: finished but not reaped by parent (entry remains). Orphan: parent died; adopted by init/systemd.

How to run a process in background that survives logout? (Processes, Signals & systemd)

nohup cmd &, tmux/screen, or better a systemd service.

What is PID 1? (Processes, Signals & systemd)

First process (systemd/init). In containers, your app becomes PID 1 and must handle signals/reap zombies (use tini).

What does systemctl enable do vs start? (Processes, Signals & systemd)

enable = start on boot (symlink); start = start now.

Load average 8 on 4-core machine, meaning? (Processes, Signals & systemd)

Avg number of runnable+uninterruptible tasks; 8 on 4 cores = overloaded (queueing). Check CPU vs IO wait.

What is PID 1 and why does it matter? (Processes, Signals & systemd)

The first process (systemd); it adopts orphans and reaps zombies; in containers your app is PID 1 and must handle signals.

Why: Links to Docker.

Real-world example: Use tini in containers.

grep vs egrep vs fgrep? (Text Processing: grep, sed, awk)

grep basic regex; grep -E (egrep) extended regex; grep -F (fgrep) fixed strings, fastest.

How to print 2nd column of a CSV? (Text Processing: grep, sed, awk)

awk -F',' '{print $2}' file or cut -d',' -f2 file.

Why sort before uniq? (Text Processing: grep, sed, awk)

uniq only collapses adjacent duplicates.

How to tail multiple logs and filter? (Text Processing: grep, sed, awk)

tail -F a.log b.log | grep --line-buffered ERROR

How to replace text across many files? (Text Processing: grep, sed, awk)

grep -rl old . | xargs sed -i 's/old/new/g'

What is xargs used for? (Text Processing: grep, sed, awk)

Converts stdin into command arguments: find . -name '*.tmp' | xargs rm; use -0 with find -print0 for spaces.

Find which endpoint returns most 5xx. (Text Processing: grep, sed, awk)

awk '$9>=500 {print $7}' access.log | sort | uniq -c | sort -nr | head (columns depend on log format).

Why: Real log analysis.

Real-world example: Check field numbers first.

How to check which process uses port 80? (Linux Networking & SSH)

sudo ss -tulpn | grep :80 or lsof -i :80.

Difference between ssh -L and -R? (Linux Networking & SSH)

-L forwards local port to remote destination; -R exposes a local service via a port on the remote server (reverse).

How does SSH key auth work? (Linux Networking & SSH)

Server has your public key; it sends a challenge encrypted with it; only your private key can answer. Private key never leaves your machine.

Ping works but curl fails. Why? (Linux Networking & SSH)

ICMP allowed but TCP port blocked/app down/TLS issue/DNS to different name. Test with curl -v, nc -zv host port.

What is a bastion host? (Linux Networking & SSH)

Hardened public jump server used to reach private instances, with logging and restricted access.

How to see DNS resolution path? (Linux Networking & SSH)

dig +trace example.com; check /etc/resolv.conf, resolvectl status.

How would you access a private DB safely? (Linux Networking & SSH)

Via bastion/SSM with SSH tunnel or port forward, no public DB exposure, audited access.

Why: Secure access.

Real-world example: SSM Session Manager port forwarding.

ext4 vs xfs? (Disk, Storage & Package Management)

ext4 general purpose, can shrink; xfs great for large files/parallel IO, can only grow.

What is LVM advantage? (Disk, Storage & Package Management)

Flexible resize, snapshots, spanning multiple disks.

What is RAID 1/5/10? (Disk, Storage & Package Management)

1 mirror; 5 striping + parity (1 disk fail); 10 striped mirrors (performance + redundancy).

How to clean a huge log safely? (Disk, Storage & Package Management)

truncate -s 0 file (not rm while in use); set up logrotate.

What does apt update vs apt upgrade do? (Disk, Storage & Package Management)

update refreshes package index; upgrade installs newer versions.

Why test mount -a? (Disk, Storage & Package Management)

Catches fstab errors before reboot to avoid boot failure.

EBS volume was enlarged in AWS; how to use the space? (Disk, Storage & Package Management)

growpart /dev/xvda 1 then resize2fs (ext4) or xfs_growfs (xfs); verify with df -h.

Why: Common cloud task.

Real-world example: No downtime needed.

Explain load average. (Performance & Troubleshooting)

1/5/15 min avg of tasks running or waiting (incl. IO on Linux). Compare with core count.

What is swap and when bad? (Performance & Troubleshooting)

Disk space used as RAM overflow; heavy swapping (si/so) kills performance.

What is OOM killer? (Performance & Troubleshooting)

Kernel kills a process (highest oom_score) when memory exhausted. See dmesg.

How to find which process is using most IO? (Performance & Troubleshooting)

iotop -o or pidstat -d 1.

What is strace? (Performance & Troubleshooting)

Traces system calls of a process; reveals file/network calls and blocking points.

What are cgroups and namespaces? (Performance & Troubleshooting)

Kernel features: cgroups limit/account resources, namespaces isolate views (pid, net, mnt...). Together they make containers.

Load average is 20 but CPU idle is high. Why? (Performance & Troubleshooting)

Load includes tasks in uninterruptible IO wait; likely disk or NFS problem. Check iowait, iostat, D-state processes.

Why: Understanding load.

Real-world example: Slow disk.

What does set -euo pipefail do? (Bash Scripting for DevOps)

-e exit on error, -u error on unset var, -o pipefail pipeline fails if any command fails.

Difference between $@ and $*? (Bash Scripting for DevOps)

"$@" keeps each argument separate; "$*" joins into one string.

How to check if a file exists? (Bash Scripting for DevOps)

[[ -f file ]] (file), -d dir, -s non-empty.

What is exit code and how to read? (Bash Scripting for DevOps)

0 success; $? gives last command status.

What is a here-doc? (Bash Scripting for DevOps)

cat <<EOF ... EOF passes multi-line text to a command.

How do you make a script idempotent? (Bash Scripting for DevOps)

Check state before acting (e.g. mkdir -p, grep -q || append), so re-running gives same result.

What does $? and $@ mean? (Bash Scripting for DevOps)

$? is the last exit code; $@ is all arguments (quote it as "$@").

Why: Scripting basics.

Real-world example: Wrapper scripts forwarding args.

Linux: level-wise (65 questions)

Beginner

Q1. What is Linux?

A free open-source Unix-like operating system kernel; distributions package it with tools.

Why: Basics.

Real-world example: Ubuntu, RHEL, Amazon Linux.

Q2. What does ls -l show?

Long listing: permissions, links, owner, group, size, date, name.

Why: Everyday command.

Real-world example: -rwxr-xr-- 1 root dev.

Q3. Explain rwx and chmod 755.

Owner rwx (7), group r-x (5), others r-x (5).

Why: Permissions are heavily tested.

Real-world example: Scripts are 755, private keys 600.

Q4. Absolute vs relative path?

Absolute starts at /; relative starts from the current directory.

Why: Navigation.

Real-world example: /etc/nginx vs ../conf.

Q5. What is sudo?

Runs a command as another user (root) if permitted by sudoers.

Why: Privilege control.

Real-world example: sudo systemctl restart nginx.

Q6. How to view a large file?

less, head, tail -f for live logs.

Why: Log reading.

Real-world example: tail -f /var/log/nginx/error.log.

Q7. What is a package manager?

Tool that installs/updates/removes software and dependencies.

Why: Provisioning.

Real-world example: apt install nginx.

Q8. Difference between > and >>?

> overwrites, >> appends.

Why: Redirection.

Real-world example: echo x >> file.

Q9. How do you find a file?

find / -name file or locate.

Why: Basic search.

Real-world example: find /var/log -name '*.log' -mtime +7.

Q10. What is the root user?

Superuser with UID 0 and full privileges.

Why: Security.

Real-world example: Avoid daily use.

Intermediate

Q1. Explain pipes and redirection.

Pipe | sends stdout of one command to stdin of another; redirection sends streams to files; stderr is fd 2.

Why: Command composition.

Real-world example: grep ERROR app.log | sort | uniq -c.

Q2. What is a process vs daemon?

Process is a running program; a daemon is a background service process.

Why: System concepts.

Real-world example: sshd is a daemon.

Q3. How to check listening ports?

ss -tulpn (modern) or netstat -tulpn.

Why: Networking debugging.

Real-world example: Find what uses port 8080.

Q4. What is systemd and a unit file?

Init system/service manager; unit files define services, timers, mounts.

Why: Service management.

Real-world example: /etc/systemd/system/app.service.

Q5. Explain inode.

Metadata structure for a file (owner, permissions, block pointers); filenames map to inodes.

Why: Filesystem depth.

Real-world example: df -i shows inode exhaustion.

Q6. Hard link vs symlink?

Hard link is another name for the same inode; symlink is a path pointer.

Why: Classic question.

Real-world example: ln -s /opt/app-v2 /opt/app.

Q7. Special permissions setuid/setgid/sticky?

setuid runs as owner, setgid group inheritance/run as group, sticky prevents deleting others' files in a directory.

Why: Security.

Real-world example: /tmp has sticky bit.

Q8. How does SSH key authentication work?

Client proves possession of private key matching a public key in authorized_keys via challenge signature; no password sent.

Why: Secure access.

Real-world example: ssh-keygen -t ed25519.

Q9. What is cron syntax?

m h dom mon dow command.

Why: Scheduling.

Real-world example: 0 2 * * * backup.sh.

Q10. grep vs sed vs awk?

grep searches, sed edits streams, awk processes columns/fields.

Why: Text processing.

Real-world example: awk '{print $1}' access.log.

Q11. What is /etc/fstab?

Defines filesystems mounted at boot.

Why: Storage.

Real-world example: Mount EBS at /data with nofail.

Q12. What are environment variables?

Key-value pairs inherited by processes; PATH decides where commands are found.

Why: Scripting/config.

Real-world example: export DB_URL=....

Q13. What is load average?

Average number of runnable/uninterruptible tasks over 1, 5, 15 minutes; compare with CPU count.

Why: Performance.

Real-world example: Load 8 on 4 CPUs means overloaded.

Q14. How to check memory usage?

free -h, vmstat, top; look at 'available' not just 'free'.

Why: Common confusion.

Real-world example: Cache is reclaimable.

Q15. What is nohup and &?

& runs in background; nohup keeps running after logout; prefer systemd/tmux for services.

Why: Process control.

Real-world example: Long job over SSH.

Advanced

Q1. Explain the Linux boot process.

BIOS/UEFI > bootloader (GRUB) > kernel + initramfs > systemd (PID 1) > targets/services > login.

Why: Deep system knowledge.

Real-world example: Rescue mode by editing GRUB.

Q2. Explain namespaces and cgroups.

Namespaces isolate views (pid, net, mnt, uts, ipc, user); cgroups limit/account resources; together they form containers.

Why: Links Linux to Docker.

Real-world example: unshare, systemd-run --property=MemoryMax=.

Q3. How does the OOM killer choose a victim?

Kernel scores processes by memory use and oom_score_adj; kills the highest to free memory.

Why: Memory incidents.

Real-world example: Protect sshd with negative adj.

Q4. Explain LVM.

Physical volumes > volume group > logical volumes; allows resizing/snapshots without repartitioning.

Why: Storage management.

Real-world example: lvextend -r to grow online.

Q5. What is strace used for?

Traces system calls to see what a process is doing (files, network, errors).

Why: Deep debugging.

Real-world example: Find a missing config path.

Q6. Explain iowait and how to find the cause.

CPU waiting for disk I/O. Use iostat -x, iotop, pidstat -d, check saturation/latency.

Why: Performance.

Real-world example: Backup job saturating disk.

Q7. TCP connection states and TIME_WAIT?

TIME_WAIT keeps closed connections briefly for delayed packets; many are normal on busy clients but may exhaust ports.

Why: Network tuning.

Real-world example: ss -s.

Q8. How would you harden a Linux server?

Patching, key-only SSH, no root login, firewall, least privilege sudo, minimal packages, auditd, fail2ban, CIS benchmarks, SELinux/AppArmor enforcing.

Why: Security.

Real-world example: Ansible hardening role.

Q9. What are ulimits and file descriptors?

Per-process limits such as open files; too low causes 'Too many open files'. Set in limits.conf or systemd LimitNOFILE.

Why: High-traffic servers.

Real-world example: Nginx with 100k connections.

Q10. Difference between kill, pkill, killall?

kill targets PID; pkill matches name pattern; killall kills all by exact name.

Why: Process control.

Real-world example: pkill -f gunicorn.

Q11. Explain swap and swappiness.

Swap extends memory using disk; swappiness controls tendency to swap; heavy swapping means memory pressure.

Why: Memory tuning.

Real-world example: Kubernetes nodes usually disable swap.

Q12. How do you troubleshoot a zombie process?

A zombie is a finished child not reaped by its parent; fix the parent (or kill it); zombies use no resources except a PID entry.

Why: Process knowledge.

Real-world example: PID 1 in containers must reap children.

Q13. What is journald and how to filter logs?

systemd's binary log; journalctl -u svc --since '1 hour ago' -p err.

Why: Modern logging.

Real-world example: Persistent storage configured in journald.conf.

Q14. Explain rsync vs scp.

rsync transfers only differences, supports resume/delete/permissions; scp copies whole files.

Why: Data transfer.

Real-world example: Backup with rsync -aHAX --delete.

Q15. tmpfs and /proc /sys?

tmpfs is RAM-backed FS; /proc and /sys are virtual filesystems exposing kernel/process info.

Why: Kernel interfaces.

Real-world example: cat /proc/meminfo.

Real-world example: Empty variable expanded to /.

Networking

What happens when you type google.com in browser? (OSI, TCP/IP & How the Web Works)

Browser cache -> DNS resolution (recursive resolver -> root -> TLD -> authoritative) -> TCP 3-way handshake -> TLS handshake -> HTTP GET -> server response -> browser renders, loading more resources.

TCP vs UDP? (OSI, TCP/IP & How the Web Works)

TCP: reliable, ordered, connection-oriented (web, SSH). UDP: connectionless, faster, no guarantee (DNS, video, QUIC).

Explain TCP 3-way handshake. (OSI, TCP/IP & How the Web Works)

SYN -> SYN-ACK -> ACK. Connection closes with FIN/ACK exchanges.

Which layer do load balancers L4 and L7 work at? (OSI, TCP/IP & How the Web Works)

L4 at transport (IP+port), L7 at application (HTTP path/header based).

What is MTU? (OSI, TCP/IP & How the Web Works)

Max packet size on a link (1500 typical). Mismatch causes fragmentation or dropped large packets.

At which layer do firewall, WAF and LB operate? (OSI, TCP/IP & How the Web Works)

Classic firewalls L3/L4, WAF L7, load balancers L4 (NLB) or L7 (ALB).

Why: Mapping tools to layers.

Real-world example: ALB path routing = L7.

How many usable IPs in /27? (IP Addressing & Subnetting (CIDR))

Public vs private IP? (IP Addressing & Subnetting (CIDR))

A virtual partition of a cluster for isolation, quotas and RBAC.

Controllers replace failed Pods, restart failing containers and reschedule from dead nodes.

Programs iptables or IPVS rules on each node to DNAT Service IPs to Pod endpoints (some CNIs like Cilium replace it with eBPF).

Every Pod gets its own IP and can reach every other Pod without NAT; a CNI plugin (Calico, Cilium, AWS VPC CNI) implements it.

Why: Networking depth.

CRDs extend the API; an operator is a controller that manages an app's lifecycle using CRDs.

HPA scales Pods; Cluster Autoscaler/Karpenter add/remove nodes for pending Pods.

Recreate kills all old Pods first (downtime); RollingUpdate replaces gradually.
