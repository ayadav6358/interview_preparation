Disk, Storage & Package Management

Intermediate Linux

Concept (What & Why)

Disk full ho jana production ka classic issue hai. Disks mount karna, LVM se resize, aur apt/yum se software manage karna aana chahiye.

Definition Deep-Dive

QuestionAnswer
Simple definitionHow disks are split, formatted, mounted and how software is installed.
Technical definitionBlock devices are partitioned (MBR/GPT) or managed by LVM, formatted with a filesystem (ext4/xfs), mounted in the tree (fstab/UUID); package managers resolve dependencies from repositories.
Why does it exist?Applications need storage and software.
What happens without it?No place to store data or install tools.
When to useProvisioning and capacity work.
When NOT to useEditing fstab without nofail on cloud disks.
Real-world analogyBuying land (disk), fencing it (partition), building on it (filesystem).

Diagram & Internal Working

Disk /dev/sdb -> partition /dev/sdb1 -> filesystem (ext4/xfs) -> mount /data
LVM:  PV (disk) -> VG (pool) -> LV (volume, resizable) -> filesystem

How it works internally (diagram explained)

New disk > lsblk sees device > partition/PV > format (mkfs) > mount attaches it at a directory > /etc/fstab makes it persistent using UUID (names like /dev/sdb can change). Packages: apt install reads the repo index, resolves dependencies, downloads and installs, and records them in the package database.

Install / Setup

sudo apt update && sudo apt install lvm2 -y

Practical Examples

Add and mount a new disk

lsblk
sudo mkfs.ext4 /dev/sdb
sudo mkdir /data && sudo mount /dev/sdb /data
blkid /dev/sdb    # copy UUID
echo 'UUID=xxxx /data ext4 defaults,nofail 0 2' | sudo tee -a /etc/fstab
sudo mount -a     # test fstab BEFORE reboot

Extend LVM volume online

sudo lvextend -L +10G /dev/vg0/data
sudo resize2fs /dev/vg0/data       # xfs_growfs /data for xfs

Find disk hogs

df -hT; df -i
sudo du -xh / --max-depth=2 | sort -h | tail
sudo lsof +L1     # deleted files still held open

Packages

sudo apt update && sudo apt install -y nginx
apt list --installed | grep nginx; apt-cache policy nginx
sudo apt remove --purge nginx; sudo apt autoremove
# RHEL: dnf install / dnf history undo

Hands-On Lab

Lab Goal

Add and mount a new disk (test VM only).

Prerequisites

  • Extra disk attached, sudo

Step 1

lsblk

Identify the new disk (for example /dev/sdb). Be certain: formatting destroys data.

Step 2

sudo mkfs.ext4 /dev/sdb && sudo mkdir /data && sudo mount /dev/sdb /data

Formats and mounts.

Step 3

sudo blkid /dev/sdb; echo 'UUID=<uuid> /data ext4 defaults,nofail 0 2' | sudo tee -a /etc/fstab && sudo mount -a

Persistent mount; mount -a validates fstab before reboot.

Real-World Problems & Fixes (Troubleshooting)

Problem: Disk shows 100% but du shows less
Cause: Deleted log file still open by a process
Fix: lsof +L1 then restart process or truncate: : > /proc/<pid>/fd/<n>.
Problem: Server fails to boot after fstab edit
Cause: Wrong UUID/entry, no nofail
Fix: Boot rescue mode, fix fstab; always test with mount -a.
Problem: 'No space left' but df has space
Cause: Inode exhaustion (millions of small files)
Fix: df -i; delete session/tmp files; tune fs for small files.

Best Practices

Reliability

  • Use UUID and nofail; monitor disk and inode usage; LVM for flexibility.

Common Mistakes

Production mistakes

  • Formatting the wrong disk.
  • fstab typo preventing boot.

Hinglish Explanation

Naya disk: lsblk → mkfs → mount → fstab (UUID ke saath, nofail). Format karne se pehle device ka naam do baar check karo.

Version / Environment Notes

  • apt for Debian/Ubuntu; dnf/yum for RHEL family. Cloud disks may appear as /dev/nvme*.

Interview Questions

Q1. ext4 vs xfs?

ext4 general purpose, can shrink; xfs great for large files/parallel IO, can only grow.

Q2. What is LVM advantage?

Flexible resize, snapshots, spanning multiple disks.

Q3. What is RAID 1/5/10?

1 mirror; 5 striping + parity (1 disk fail); 10 striped mirrors (performance + redundancy).

Q4. How to clean a huge log safely?

truncate -s 0 file (not rm while in use); set up logrotate.

Q5. What does apt update vs apt upgrade do?

update refreshes package index; upgrade installs newer versions.

Q6. Why test mount -a?

Catches fstab errors before reboot to avoid boot failure.

Q7. EBS volume was enlarged in AWS; how to use the space?

growpart /dev/xvda 1 then resize2fs (ext4) or xfs_growfs (xfs); verify with df -h.

Why: Common cloud task.

Real-world example: No downtime needed.
