Text Processing: grep, sed, awk

Intermediate Linux

Concept (What & Why)

Logs aur config par kaam karne ke liye grep/sed/awk/cut/sort/uniq roz use hote hain. Incident ke time 5 minute mein answer nikalne ki power.

Definition Deep-Dive

QuestionAnswer
Simple definitionTools that search and transform text: logs, configs and command output.
Technical definitiongrep filters lines by regex, sed edits streams, awk processes records/fields, sort/uniq/cut/tr/jq combine in pipelines operating on stdin/stdout.
Why does it exist?Logs and configs are text; DevOps solves problems by filtering them.
What happens without it?Scrolling through huge files manually.
When to useLog analysis, config edits, reports.
When NOT to useParsing structured JSON with regex (use jq).
Real-world analogySieves and scissors for text.

Diagram & Internal Working

access.log --grep 500--> awk '{print $1}' --> sort --> uniq -c --> sort -rn --> head
(filter)                 (pick field)         (group)   (count)     (rank)

How it works internally (diagram explained)

Each tool reads a stream line by line, applies a rule and writes results, so they can be chained: grep reduces lines, awk extracts a column, sort | uniq -c counts, sort -nr | head ranks.

Install / Setup

# built-in. Extra: sudo apt install jq -y   (JSON)

Practical Examples

Top 10 IPs hitting server

awk '{print $1}' /var/log/nginx/access.log | sort | uniq -c | sort -rn | head

Count 5xx errors per URL

awk '$9 ~ /^5/ {print $7}' access.log | sort | uniq -c | sort -rn | head

grep power

grep -rn "ERROR" /var/log/app/ --include="*.log"
grep -E "timeout|refused" app.log
grep -B2 -A5 "Exception" app.log      # context lines
zgrep "ERROR" app.log.*.gz

sed replace in config

sed -i 's/^port=.*/port=8080/' app.conf
sed -n '10,20p' file; sed '/^#/d' file    # print range; delete comments

jq for JSON

curl -s api/users | jq '.[] | select(.active) | .email'
aws ec2 describe-instances | jq -r '.Reservations[].Instances[].InstanceId'

Important Commands Explained

awk '{print $1}' access.log | sort | uniq -c | sort -nr | head
What does it do?
Top 10 client IPs in an nginx log.
Important options
awk -F, sets separator; $1 first field, NF count.
Expected output
Count and IP pairs.
Common mistake
Forgetting sort before uniq.
Troubleshooting
Wrong columns? Print with awk '{print NF, $0}' | head.
grep -RIn --exclude-dir=.git 'ERROR' /var/log/app
What does it do?
Search recursively with line numbers.
Important options
-i ignore case, -v invert, -E regex, -A/-B context.
Expected output
path:line:text.
Common mistake
Unquoted pattern expanded by the shell.
Troubleshooting
No output? Check permissions and path.
sed -i.bak 's/old/new/g' file
What does it do?
In-place replacement with backup.
Important options
-n + p, -E, addresses.
Expected output
None.
Common mistake
Editing without a backup.
Troubleshooting
macOS sed needs -i ''.

Hands-On Lab

Lab Goal

Analyse a sample access log.

Prerequisites

  • Linux terminal

Step 1

printf '1.1.1.1 GET /a 200\n2.2.2.2 GET /b 500\n1.1.1.1 GET /c 200\n' > log.txt

Creates sample data.

Step 2

awk '{print $1}' log.txt | sort | uniq -c | sort -nr

Counts requests per IP: 2 1.1.1.1 first.

Step 3

awk '$4>=500' log.txt

Shows only server errors.

Step 4

echo '{"a":1}' | jq .a

jq extracts JSON fields properly.

Real-World Problems & Fixes (Troubleshooting)

Problem: Need to find which deploy caused errors spike
Cause: Logs are huge
Fix: grep -c ERROR per hour: awk '{print substr($4,2,14)}' | uniq -c to see spike time and correlate with deploy.
Problem: sed -i broke a config file
Cause: No backup taken
Fix: Use sed -i.bak ... and diff; keep configs in Git.

Best Practices

Production

  • Use zcat/zgrep for rotated logs.

Common Mistakes

Beginner mistakes

  • uniq without sort.

Hinglish Explanation

Log dekhna ho to grep se filter, awk se column nikalo, sort | uniq -c se count karo. JSON ke liye jq use karo.

Memory Tricks

ConceptMemory trick

Interview Questions

Q1. grep vs egrep vs fgrep?

grep basic regex; grep -E (egrep) extended regex; grep -F (fgrep) fixed strings, fastest.

Q2. How to print 2nd column of a CSV?

awk -F',' '{print $2}' file or cut -d',' -f2 file.

Q3. Why sort before uniq?

uniq only collapses adjacent duplicates.

Q4. How to tail multiple logs and filter?

tail -F a.log b.log | grep --line-buffered ERROR

Q5. How to replace text across many files?

grep -rl old . | xargs sed -i 's/old/new/g'

Q6. What is xargs used for?

Converts stdin into command arguments: find . -name '*.tmp' | xargs rm; use -0 with find -print0 for spaces.

Q7. Find which endpoint returns most 5xx.

awk '$9>=500 {print $7}' access.log | sort | uniq -c | sort -nr | head (columns depend on log format).

Why: Real log analysis.

Real-world example: Check field numbers first.
